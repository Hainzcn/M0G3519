## 0. 结论摘要

小球"滚过中心点再摆动微调"不是调参问题，而是结构问题：

> 被控对象是**双积分环节**（光滑管壁 + 大惯性钢球，几乎无自然阻尼），而摆角指令到小球实际受力之间存在**约 150~300 ms 的等效纯滞后与速率限制**。纯反馈控制（无论单环 PID 还是串级）在这个滞后下要么带宽太低回位慢，要么必然超调。

一次回位需要**二自由度（2-DOF）控制结构**，并叠加同类成功项目验证过的两条硬约束：

1. **前馈承担全部标称运动**：Jerk 受限的 S 曲线轨迹 → 动力学逆解得到摆角时间序列 → 按辨识出的总滞后 τ **提前**下发；
2. **反馈只修残差，且每拍以中心为终点做在线三角速度**：临界阻尼以上（ζ ≥ 1）+ **速度–位置耦合的制动抛物线限速**（超限则加大回拉角，保证 $v^2 \le 2 a_{brake}|e|$），短行程自然呈"先加后减"三角形，无巡航段；
3. **全链路状态预测（Smith 型）**：估计器不仅补视觉延迟，还要用已下发的摆角指令历史把球状态预测到"当前指令生效的时刻"；
4. **静摩擦 / 奇异点 / 末端捕获**：中心死区用定向破静摩擦 + 捕获区微积分；动力学/连杆奇异点做硬限与降级；制动收尾带小残余速度进捕获区。

其中第 1、3 条是现有代码缺失的关键；第 2 条当前参数明确不满足（ζ = 0.5），且缺少制动抛物线安全网；第 4 条现有 bang-bang 摩擦补偿不够稳健。

## 2. 问题机理诊断

### 2.1 被控对象：无阻尼双积分

$$\ddot{x} = -k\,g\sin\alpha - k\,a_{car}\cos\alpha,\qquad k = 0.860739440\ (\text{240 fps 初步计时辨识，见 §5.1})$$

管壁光滑、钢球惯性大 ⇒ 对象本身**没有阻尼项**。所有阻尼必须由控制器"制造"，而制造阻尼依赖速度信息和及时的执行——两者恰恰都被滞后链破坏。

### 2.2 单位置环为何对称振荡

$\alpha \propto K_p e_x$ 代入上式（小角度）得 $\ddot{x} = -\omega^2 x$：**无阻尼谐振子**。振幅只能靠滚动摩擦缓慢衰减——与观测到的"以中点为中心对称震荡、几秒后停"完全一致。这不是参数问题，是结构性缺陷（缺速度阻尼项）。

### 2.3 串级为何"减速冲过中心"

**(a) 增益本身欠阻尼。** 忽略滞后，串级闭环特征方程：

$$s^2 + K_v s + K_v K_p = 0,\qquad \zeta = \frac{1}{2}\sqrt{K_v / K_p}$$

当前 `BALANCE_POSITION_LOOP_GAIN=2.0`、`BALANCE_VELOCITY_LOOP_GAIN=2.0` ⇒ **ζ = 0.5，理想无滞后情况下也有 ≈16% 超调**。一次回位要求 ζ ≥ 1，即 **K_v ≥ 4·K_p**。

**(b) 加速度指令到球受力的滞后链（当前均未被补偿）：**

| 环节 | 量级 | 备注 |
|------|------|------|
| 相机曝光+帧周期 | 8~17 ms | 60 fps |
| 视觉处理+传输 | proc_ms+3 ms | 已补偿（≤30 ms，仅位置前推） |
| α-β 滤波速度滞后 | **~100 ms** | β=0.16 @60fps，时间常数≈dt/β；MCU 估计器融合后仍残留大半 |
| 外环 ZOH | 0~20 ms | |
| 命令周期 | 0~20 ms | |
| 摆角限速整形 | **70~270 ms** | 30°/s；换向摆 2~3° 需 70~100 ms，极限 ±4° 对摆需 267 ms |
| Emm42 内部加减速 | 待实测 | acc=20 的斜坡不可忽略，见 §5.2 |

**合计约 150~300 ms。** 球以 60 mm/s 巡航时，从"控制器决定制动"到"斜面真的反向"球已经又走了 **9~18 mm**——这正是"减速过程滚过中心点"的直接原因。滞后在闭环里表现为相位损失，进一步压低实际阻尼，形成"过冲→回摆→微调"的极限环。

**(c) 前馈存在但相位不对。** `brake_lookahead_s = 0.12 s` 是对参考轨迹的固定超前，方向正确但：① 数值是拍的，未与实测滞后对齐；② 超前只作用于参考，反馈通道和摆角整形仍原样滞后；③ 摆角限速整形放在控制器**之后**，等于把控制器精心算出的加速度again打了折扣，且控制器不知情。

**(d) 摩擦死区。** 低速摩擦补偿（0.045 m/s²，阈值 10 mm/s / 4 mm）是 bang-bang 式的，容易在中心附近激起小极限环——正是同类项目强调"要有静摩擦力处理"的原因，见 §3.5。

**(e) 无超限意识。** 现有串级用常数球速上限，不检查 $v^2 \le 2a_{brake}|e|$。一旦加速过猛或滞后导致进入"刹不住"区，就只能过冲再回调——同类项目的"超限补偿 / 速度位置耦合"正针对此，见 §3.2。

### 2.4 为什么"怎么调参都不行"

双积分 + 纯滞后 τ 的反馈回路，穿越频率受限于 ω_c ≲ 0.3~0.5/τ。取 τ=0.2 s ⇒ ω_c ≤ 1.5~2.5 rad/s。想让 25 cm 行程几秒内一次到位，需要的等效带宽恰好卡在这个上限附近——调高增益立刻振荡，调低增益回位慢且被摩擦卡住。**参数空间里不存在同时满足"快"和"不超调"的点，必须改结构**（2-DOF + 在线三角速度安全网 + 摩擦/奇异点分区）。

## 3. 目标控制律：二自由度结构

```text
                       ┌─────────────────────────────────────────┐
 target ──► S曲线轨迹  │ x_ref,v_ref,a_ref (标称大行程)          │──► 逆解 ──► α_ff(t+τ)
            (jerk受限) └──────────────────┬──────────────────────┘
                                          │
 vision ──► 估计器 ──► Smith预测 ──► 每拍以中心为终点的在线三角速度 ──► a_des ──► 逆解 ──► α_cmd
            (200Hz)   (τ_v+τ_a)      (v–x 耦合制动抛物线 + ζ≥1 残差反馈)
                                      + 静摩擦破静 / 奇异点降级 / 捕获区 Ki
                                                                          │
                                                                          ▼
                                                                    IK → Emm42
```

**与同类成功经验的对应关系（两条都有价值，已吸收）：**

| 外部经验 | 本方案落点 | 判断 |
|----------|------------|------|
| "速度和位置耦合控制回拉角，先加后减，每次回调以中点为终点" | §3.2 在线三角速度 / 制动抛物线 | **高价值**。本质是双积分时间最优（bang-bang）的切换曲线；短行程强制三角形、长行程梯形。现有 `ball_motion_profile` 只是离线参考，**每控制拍用当前 (x,v) 重算到 (0,0)** 才是他们说的"每次回调" |
| "超限补偿，避免加速度过快拉不回来" | §3.2 抛物线外侧 → 最大回拉角 | **高价值**。状态一旦越过 $v^2 = 2a|e|$，普通串级无法一次回位 |
| "静摩擦力处理、奇异点处理" | §3.5 | **高价值**。光滑管静摩擦小但中心死区真实存在；动力学 `asin` 饱和与连杆极限是本机奇异点 |

补充：S 曲线（§3.1）与在线三角速度（§3.2）**不冲突**——前者服务"已知目标点迁移"的标称前馈（jerk 可执行）；后者是**每拍重规划的反馈/安全层**，把中心当作终端状态。稳态居中任务下后者是主路径，±50 mm 序列演示时两者同时工作。

### 3.1 前馈：Jerk 受限 S 曲线 + 时间超前（标称大行程）

- **为什么 S 曲线**：梯形速度的加速度是阶跃，而摆角速率限制 30°/s 决定了球加速度变化率上限
  $\dot a_{max} = k\,g\cos\alpha\cdot\dot\alpha_{max} \approx \tfrac{5}{7}\times 9.81\times 0.524 \approx 3.6\ \text{m/s}^3$。
  用 jerk ≤ 0.7×该值（留裕量）规划 S 曲线，则前馈摆角序列**天然满足执行器速率约束**，摆角整形环节不再意外削波。
- **逆解**：$\alpha_{ff}(t) = \arcsin\!\big(-a_{ref}(t)/(k g)\big) - \arctan(a_{car}/g)$（沿用现有 `balance_control.c` 逆解式）。
- **时间超前**：α_ff 按 **t+τ_a** 下发（τ_a = 执行链滞后，§5.2 实测），取代现在拍脑袋的 `brake_lookahead_s=0.12`。参考状态 (x_ref, v_ref) 给反馈用的版本**不超前**，两者分离。
- **末端捕获规划**：制动段不规划到 v=0@x=0，而是规划到 **v = v_creep（≈8~12 mm/s）@ x = -3~-5 mm**，随后摆杆归平，让摩擦收尾（与 §3.5 衔接）。

### 3.2 在线三角速度 + 超限回拉（速度–位置耦合，每拍以中心为终点）

同类成功开发者描述的核心，正式化为**双积分时间最优控制的切换曲线 / 最简路径规划**：

每个外环拍（20 ms），用预测状态 $(x_p, v_p)$，终点固定为中心 $(0, 0)$：

1. **制动距离**：$d_{brake} = v_p^2 / (2 a_{brake}^{avail})$，其中
   $a_{brake}^{avail} = 0.7\sim0.8\cdot k g \sin\alpha_{max}$（留裕量），并对滞后降额：可用行程取 $\max(|x_p| - |v_p|\tau,\ 0)$。
2. **相位判决（强制三角 / 梯形）**：
   - 若 $|v_p|$ 方向背离中心，或 $d_{brake} \ge$ 可用行程 → **超限**：立刻最大回拉角（$a_{des} = -\mathrm{sign}(v_p)\,a_{brake}^{avail}$），不再加速；
   - 若未达巡航且 $d_{brake} <$ 可用行程的前半 → **加速段**（向中心加速）；
   - 否则 → **减速段**（向中心制动）。
   短行程（±50 mm 内常见）无巡航，剖面就是三角形；这就是"尽可能让球呈现加速度先加后减"。
3. **速度指令耦合限幅**（串级实现时等价于）：

  $$v_{lim}(x_p) = \min\!\Big(v_{max},\ \sqrt{2\,a_{brake}^{avail}\cdot\max(|x_p| - |v_p|\,\tau,\ 0)}\Big)$$

   $v_{cmd}$ 再经 ζ≥1 的速度环变成 $a_{fb}$；超限时 $v_{lim}$ 塌缩，回拉角自动顶满。

4. **与纯串级的区别**：旧串级用常数 `BALANCE_MAX_BALL_VELOCITY_MPS` 限速，不知道"还能不能刹住"；本层把 **位置误差直接写进速度上限**，过冲在进入危险区之前就被切掉。

5. **角色划分**：S 曲线前馈正常时球速应始终低于 $v_{lim}$（限幅不触发）；扰动/模型失配时本层接管。遥测若频繁触发超限标志，回 §5 重标，**不要**靠加大 Kp 硬拉。

ζ≥1 残差反馈仍建议起点：`Kp=1.0 s⁻¹, Kv=5.0 s⁻¹`（在 τ≈0.15 s 相位预算内）。前馈健康时 a_fb 峰值应 <0.1 m/s²。

### 3.3 Smith 型全链路预测（关键新增）

现有估计器只把视觉位置前推 proc_ms+3 ms。重构为：

1. 维护最近 N 拍**已下发摆角指令环形缓冲**（N·20 ms ≥ τ_a）；
2. 每个控制拍，从最新融合状态出发，用模型 $\ddot x = -kg\sin\alpha_{cmd}(t-\tau_a+\Delta)$ 沿指令历史**前推 τ_a**，得到"本拍指令生效时刻"的预测状态；
3. **§3.2 的三角速度 / 抛物线限速必须吃预测状态 $(x_p,v_p)$**，不能吃当前估计——否则切换曲线会因滞后沿抛物线抖振。

这一步把滞后从反馈回路中移出（模型准确的前提下），是允许 ζ≥1 与制动抛物线真正起作用的前提。Emm42 位置查询（10 ms）用于**校正**执行器模型，而不是直接闭环。

### 3.4 执行链改造

- **消除双重整形**：目前 MCU 摆角限速整形（30°/s+600°/s²）与 Emm42 内部加减速（rpm/acc）串联，总响应不可知。改为：MCU 整形作为**唯一权威轨迹**（其输出即 §3.3 预测模型的输入），Emm42 参数设到"跟得上 MCU 整形"即可（rpm 足够高、acc 足够陡，台架实测确定）；或反过来完全信任 Emm42、删掉 MCU 整形——二选一，不并存。
- **提高摆角速率上限**：30°/s 对应换向 ~100 ms 滞后。机械允许的话提到 60~90°/s（电机侧 90 RPM=540°/s，传动比≈4，裕量充足），滞后链直接减半——这也直接增大 $a_{brake}^{avail}$，放宽 §3.2 抛物线。
- 若 Emm42 位置模式斜坡实在慢，评估改用**速度模式高频流式指令**（MCU 直接控制摆角速率），执行器模型退化为一阶惯性，预测更简单。

### 3.5 静摩擦处理与奇异点处理

#### 3.5.1 静摩擦 / 滚动摩擦

光滑管摩擦小，但中心附近仍会出现"指令有加速度、球不动"或 bang-bang 摩擦补偿激起极限环（现状 `BALANCE_LOW_SPEED_FRICTION_ACCEL`）。处理分层：

| 区段 | 条件（量级，台架标定） | 动作 |
|------|------------------------|------|
| 运动区 | \|v\| ≥ v_stick 或 \|e\| ≥ x_capture | 正常三角速度 + ζ≥1 反馈；模型用滚动摩擦 a_f 前馈抵消 |
| 破静区 | \|e\| > x_dead 且 \|v\| < v_stick 持续 N 拍 | 输出定向破静脉冲：短时 α = ±α_break（略大于静摩擦对应角），球一旦动起来立刻退出，禁止持续顶角 |
| 捕获区 | \|e\| < x_capture 且 \|v\| < v_creep | 摆杆归平 + 小 Ki（限幅 ±0.05 m/s²，出区清零）；**废除**持续 bang-bang 摩擦补偿 |
| 已停中心 | \|e\| < x_dead 且 \|v\| ≈ 0 | α→0，Ki 冻结，避免积分爬行导致微振 |

关键原则：**破静用脉冲、稳态用摩擦自然停、积分只在捕获区短时启用**——与"末端 v_creep 进捕获区"一致，避免在零速奇点附近用大增益硬拧。

#### 3.5.2 奇异点 / 退化点（本机三类）

1. **动力学奇异（asin 饱和）**：当 $|a_{des}| \ge k g$（再加车加速度项），`asinf` 自变量越界——物理上摆角已无法提供更大球加速度。现有代码钳到 ±1 后仍继续积分误差会"装死"。处理：置 `DYNAMICS_SATURATED`；超限时**不再累加位置误差积分**；外环改为按 §3.2 最大回拉保持，并触发边缘恢复逻辑；遥测报警。
2. **连杆/行程奇异**：几何 IK 无解或超出 `BALANCE_MAX_LEVER_ANGLE_DEG` / 电机跟丢。处理：软限幅前提前降 $a_{brake}^{avail}$；连续 unreachable / follow-error → 已有 fault 锁存，保持。
3. **状态奇异（中心零速）**：$(x,v)\approx(0,0)$ 时方向信号噪声主导，串级符号乱跳。处理：进入捕获区后切断三角速度相位机，只保留 §3.5.1 捕获策略；速度死区内不对噪声做符号翻转。

## 5. 参数辨识（重构前必做）

### 5.1 滚动因子 k 与摩擦

- 摆杆固定在 2°/3°/4°，从端部释放小球，视觉记录 x(t)，二次拟合得 a，回归 $a = k g\sin\alpha - a_f$ 得 **k 和滚动摩擦 a_f**。
- 劈开水管若为半圆槽且球单点接触，理论 k=5/7；若球骑在两条切边上，有效滚动半径变小，k 会明显低于 5/7——**必须实测**。
- 标定 v_creep：放平摆杆，不同初速下滑停距离。
- **静摩擦角 α_stick**：摆杆从 0 极缓慢增大，记录球刚开始滚动的最小角；破静脉冲 α_break ≈ 1.2~1.5·α_stick。同步得到 v_stick（认为"已动"的速度阈值）。

### 5.2 执行链阶跃响应（τ_a）

- 静态（无球）下发摆角阶跃 ±1°/±2°/±4°，用 10 ms Emm42 位置查询记录实际电机角 → 反解实际摆角，测得**纯滞后 + 等效速率/时间常数**。
- 扫描 Emm42 rpm(60/90/120)×acc(10/20/50)，选"斜坡时间 ≪ MCU 整形时间"的组合。
- τ_a 写入 `BALANCE_ACTUATOR_DELAY_MS`，前馈超前、Smith 预测、§3.2 抛物线降额共用。

### 5.3 视觉链路延迟复核

- MCU 打时间戳对拍 capture_ms/接收时刻，确认端到端 τ_v；若速度改 MCU 侧估计，复测速度相位。

### 5.4 制动能力与超限边界（支撑 §3.2）

- 摆杆固定最大可用角（如 ±4°），球从中心附近给初速，测实际制动加速度，取 0.7~0.8 倍写入 $a_{brake}^{avail}$。
- 人为制造超限初态（较大初速 + 靠近中心），确认最大回拉能在边缘前刹住；据此微调降额系数与 α_max。

## 6. 整定顺序与验收标准

整定顺序（每步只动一件事）：

1. 完成 §5 辨识，填入 k、a_f、α_stick、τ_a、v_creep、$a_{brake}^{avail}$；
2. **纯前馈开环验证**：反馈置零，跑 0→+50 mm S 曲线，球应到 ±8 mm 内；
3. 接入 Smith 预测 + **仅抛物线限速 / 三角相位机**（Kp/Kv 仍较小），验证偶发扰动下不进不可刹区、剖面呈先加后减；
4. 打开 ζ≥1 残差反馈，确认 a_fb 峰值 <0.1 m/s²、超限标志极少触发；
5. 启用破静脉冲 + 捕获区 Ki，压最后 ±4 mm，确认中心无持续微振；
6. 最后才提 v_max / 压 S 曲线时间。

验收标准（对应 ±50 mm 阶跃）：

| 指标 | 要求 |
|------|------|
| 中心穿越次数 | ≤1 次（目标 0 次） |
| 超调 | ≤5 mm |
| 稳定时间（进入 ±4 mm 不再出） | ≤2.5 s |
| 稳态偏差 | ≤±4 mm |
| a_fb 峰值 | <0.1 m/s²（前馈健康度） |
| 速度剖面 | 短行程可见清晰三角（先加后减）；无"加速到顶再冲过中心" |
| 超限标志 | 正常回位过程中不触发；人为大扰动触发后能一次拉回 |
| 中心微振 | 稳态 5 s 内摆角指令不出现持续变号 bang-bang |

## 7. 风险与备选

- **模型失配风险**：Smith 预测在 k 或 τ_a 标错 >30% 时会引入反相修正。缓解：用"实测摆角 vs 模型摆角"残差自校验，超阈值退化为仅视觉延迟补偿；同时 §3.2 抛物线仍提供独立安全网。
- **抛物线降额不足**：τ 低估会导致沿切换曲线抖振。宁肯多降额（回位稍慢）也不要贴着 $v^2=2a|e|$ 运行。
- **破静脉冲过大**：α_break 过大又会把球打出捕获区。必须由 §5.1 的 α_stick 标定，并限制脉冲宽度（建议 1~2 个外环拍）。
- **机械间隙**：连杆/铰链空程会在换向瞬间产生摆角死区，若 §5.2 发现明显回差，IK 后加方向相关间隙补偿。
- **备选控制律**：2-DOF + 在线三角速度调通后若仍要提速，可将 [x, v, α] 做 LQR/极点配置，前馈与抛物线安全网保留——不推荐一开始就上。

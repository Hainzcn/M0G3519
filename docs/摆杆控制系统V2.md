# 摆杆控制系统 V2

V2 将静态回中和第三问往返拆成两个互斥控制器。生产路径不再包含位置/速度串级、MCU 状态估计、球参考轨迹、摆杆二次轨迹或底盘加速度前馈。

## 坐标与模块

- 球位置 `+x` 指向第三问 `+5 cm` 端。
- 正摆杆角表示 `+x` 端抬高，因此负摆角使球向 `+x` 加速。
- `lever_actuator` 是 Emm42、连杆映射和硬件符号的唯一所有者。
- 所有可调参数集中在 `balance_config.c`。

## V1 回中

V1 使用 `WAIT_VISION/HOLD/ACCEL/CRUISE/BRAKE/SETTLE` 状态机，目标固定为标定物理 O 点。每次动作锁存方向，并用下式判断制动：

```text
u = max(direction * velocity, 0)
remaining = max(direction * -position, 0)
d_stop = u * 0.22 + u^2 / (2 * a_brake[direction]) + 0.003
```

达到 `d_stop` 后切换固定制动摆角，同一次动作不允许从 `BRAKE` 返回加速。视觉测量超过 100 ms 时立即请求中性角，连续 3 个有效帧后重新规划。MCU 只做一次最多 30 ms 的传输延迟前推，不在帧间积分。

## SW1

SW1 是绝对时序纯开环：

```text
-1.0 deg / 900 ms
+1.1 deg / 520 ms
 0.0 deg / 200 ms
+0.8 deg / 820 ms
-0.6 deg / 1220 ms
 0.0 deg / 200 ms
```

首个命令成功下发时锁存起点，后续截止时间不顺延。阶段迟到超过 50 ms 或总时间超过 4800 ms 会回中并锁存故障。视觉丢失不影响 SW1；只有新鲜视觉确认 `|x|>=120 mm` 时，安全监视器才中断并复用 V1 回中。完成后保持中性角和 `SW1_COMPLETE`，不会自动回中心。

## 调参纪律

SW1 先以 20 ms 步进调整四段时长，再以 0.1 度步进调整四个摆角。V1 只调整两个方向制动减速度、总延迟和停车余量。禁止重新加入估计器增益、串级环增益、轨迹前视和额外边缘回拉增益。

UART3 调试遥测使用 `A5 5A 03 82 2A` 的 42 字节 V3 帧；主机流解析器仍兼容历史 V1/V2 帧。

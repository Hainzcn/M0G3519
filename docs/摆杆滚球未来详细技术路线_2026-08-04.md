## 1. 最终技术决策

新控制器采用以下主线：

> 以 `G431_26H-master` 的时间戳 Alpha-Beta 观测器、位置外环、制动速度包络、球速反馈和步进电机速度模式为主体；只吸收第二个项目的近目标增阻尼、到位滞回和任务事件前馈思想。

首个可上机版本只包含四个核心变量：

```text
估计位置 x
估计速度 v
目标球速 v_ref
电机速度 motor_rpm
```

明确不恢复以下 V2 路线：

- 不做钢球动力学逆解；
- 不做水管曲率精确抵消；
- 不做 Smith 预测和命令历史前推；
- 不生成钢球 S 曲线或梯形参考轨迹；
- 不使用多组互相切换的制动、捕获、破静控制律；
- 不要求新代码兼容旧 `balance_control` 的内部状态。

新方案仍使用少量运动学标定，但其用途仅限于：

- 建立摆杆水平零位；
- 将摆杆角速度换算为电机 RPM；
- 建立电机软限位和硬限位。

这些换算不是钢球动力学模型，也不承担回位精度。最终误差由视觉闭环消除。

## 2. 两个开源项目的取舍

| 内容 | 决策 | 说明 |
|---|---|---|
| 项目一 Alpha-Beta 观测器 | 采用 | 使用相机真实时间戳，MCU 统一估计速度 |
| 项目一位置外环生成目标球速 | 采用 | 外环和执行器职责清晰 |
| 项目一 `sqrt(2*a*e)` 制动包络 | 采用 | 作为目标速度限幅，不作为精确模型 |
| 项目一球速反馈输出摆杆角速度 | 采用 | 与本项目步进电机速度模式匹配 |
| 项目一位置积分 | 后置 | P 控制稳定后才允许加入 |
| 项目一球加速度阻尼 `Ka` | 后置且可选 | 差分噪声风险高，不是 MVP 必需项 |
| 项目一车辆加速度前馈 | 静态闭环验收后采用 | 先解决静态回中 |
| 项目一 LADRC | 暂不采用 | 默认成功方案是 PID，LADRC 还改变执行接口 |
| 项目二近目标增大 D 阻尼 | 选择性采用 | 只保留连续、有限的增益调度 |
| 项目二到位位置与速度双判据 | 采用 | 配合进入/退出滞回 |
| 项目二起步/停车事件 | 采用事件概念 | 用于提前激活连续前馈 |
| 项目二固定大角度、固定时长动作 | 不采用 | 机械和任务依赖过强 |
| 项目二未除 `dt` 的速度估计 | 不采用 | 参数不可移植 |

## 3. 坐标、单位和符号

所有新模块统一使用 SI 单位：

| 量 | 符号 | 单位 |
|---|---|---|
| 钢球位置 | `x` | m |
| 目标位置 | `x_ref` | m |
| 钢球速度 | `v` | m/s |
| 目标球速 | `v_ref` | m/s |
| 摆杆物理角 | `theta` | deg |
| 摆杆角速度 | `omega` | deg/s |
| 电机速度 | `motor_rpm` | RPM |
| 控制周期 | `dt` | s |

逻辑方向固定为：

- `x > 0`：钢球位于摆杆前端一侧；
- `theta > 0`：摆杆前端抬高；
- `theta > 0` 会使钢球向 `x < 0` 方向加速；
- `omega > 0`：摆杆前端正在抬高。

按该约定，位置误差为：

```text
e = x - x_ref
```

控制公式的逻辑符号为：

```text
v_ref = -position_controller(e)
omega  = +velocity_controller(v - v_ref)
```

电机安装方向只允许在执行器适配层使用一个 `motor_sign` 修正。视觉方向错误也只允许在视觉适配层修正，禁止在控制公式内散落负号。

## 5. 视觉与状态观测器

### 5.1 单一观测器原则

视觉端发送经过坐标标定的原始钢球位置和采集时间戳。MCU 是钢球速度估计的唯一所有者。

现有视觉端如果仍运行 Alpha-Beta 滤波，应改为输出滤波前位置，避免“相机滤一次、MCU 再滤一次”。视觉端现有速度字段可暂时保留作遥测对照，但不得进入新控制律。

### 5.2 Alpha-Beta 更新

收到一个新的、有效的视觉帧时：

```text
dt     = (capture_ms - last_capture_ms) * 0.001
x_pred = x_hat + v_hat * dt
r      = x_meas - x_pred
x_hat  = x_pred + alpha * r
v_hat  = v_hat + beta * r / dt
```

控制拍读取状态时，再从最后一次采集时刻外推到当前控制时刻：

```text
age = processing_ms
    + calibrated_transport_ms
    + (mcu_now_ms - received_ms)

x_control = x_hat + v_hat * age
v_control = v_hat
```

`capture_ms` 只做相邻帧时间差，不与 MCU 绝对时间直接相减，因此不要求两颗处理器时钟同步。

### 5.3 初始参数

```text
alpha = 0.85
beta  = 0.15
```

这两个值只作为项目一成功配置的起点。最终参数必须使用本机原始位置日志检查后确定。

### 5.4 有效性与异常处理

观测器必须处理：

- `boot_id` 改变：重置观测器；
- 时间戳重复：不更新；
- 时间戳回退：等待新会话并重置；
- `dt <= 0` 或 `dt > 80 ms`：重置速度，不做正常更新；
- 位置超出机械可见范围：拒绝；
- 单帧隐含速度超过物理上限：拒绝并等待连续可信帧；
- 连续 80 ms 无可信新帧：退出 ACTIVE；
- 视觉恢复：至少连续 3 帧可信后重新进入闭环。

异常帧不能用模型补成“看起来合理”的状态。视觉失效期间不继续积分球状态。

### 5.5 观测器准入标准

控制电机前先完成只读观察测试：

- 钢球静止 10 s，估计速度绝对值 95% 样本不超过 `5 mm/s`；
- 手动缓慢推动钢球，速度方向始终正确；
- 相同方向匀速滚动时，速度无明显周期性反号；
- 丢 1 至 2 帧时外推位置连续；
- 超过 80 ms 无新帧时可靠判无效；
- 重捕获时不出现旧速度直接继承。

未通过本节，不得开始闭环调参。

## 6. 最小控制律

### 6.1 位置修正滞回

```text
if inactive and |e| >= e_on:
    position_active = true

if active and |e| <= e_off:
    position_active = false

e_used = position_active ? e : 0
```

建议初始值：

```text
e_on  = 4 mm
e_off = 2 mm
```

滞回只决定是否修正位置，不代表钢球已经静止。

### 6.2 制动目标速度包络

```text
v_limit = min(v_max, sqrt(2 * a_envelope * |e_used|))
```

`a_envelope` 是“接近中心时允许多快”的调参量，不宣称等于真实钢球制动加速度。它越小，目标速度越保守、减速越早。

MVP 阶段位置控制只用 P：

```text
v_ref = -clamp(Kp * e_used, -v_limit, +v_limit)
```

首版禁止积分：

```text
Ki = 0
```

### 6.3 球速反馈

```text
velocity_error = v_control - v_ref
omega_cmd = Kv * velocity_error
omega_cmd = clamp(omega_cmd, -omega_max, +omega_max)
```

该式直接输出摆杆角速度，不输出摆杆目标角，也不反解钢球目标加速度。

### 6.4 近目标增阻尼

只有基础 P + Kv 闭环已经稳定、但仍有可重复的小幅过冲时，才允许吸收项目二的近目标增阻尼：

```text
approaching = (e * v_control < 0)

if approaching and |e| < e_near:
    near_scale = 1 + k_near * (1 - |e| / e_near)
else:
    near_scale = 1

Kv_effective = Kv * clamp(near_scale, 1, near_scale_max)
```

建议：

```text
e_near         = 20 mm
k_near         = 0.5
near_scale_max = 1.5
```

首版 `k_near=0`。禁止同时复制项目二的速度平方增益、距离增益、接近增益和强制舵机回中规则。

### 6.5 后置位置积分

只有以下条件同时成立时才考虑 `Ki`：

- P + Kv 已经连续稳定；
- 左右两侧都能回中；
- 剩余误差具有固定方向和可重复性；
- 水平零位已经复核；
- 误差不是视觉零点偏差。

积分只在新视觉帧到达时更新，并且必须满足：

```text
position_active
observer_valid
output_not_saturated
|e| < integral_zone
```

积分对 `v_ref` 的贡献单独限幅到 `2~3 mm/s`。进入静态锁定、视觉失效、目标切换或输出饱和加深时冻结或清零。

### 6.6 后置球加速度阻尼

`Ka` 不是首版必要项。只有近目标增阻尼仍无法解决速度衰减，而速度观测质量已经通过验收时，才进行 A/B 测试：

```text
a_raw = (v_new - v_previous) / dt_camera
a_f   = a_f + alpha_a * (a_raw - a_f)

omega_cmd += Ka * a_f
```

`a_f` 只在新视觉帧上更新。加入 `Ka` 后若电机换向次数或高频噪声明显增加，应立即退回 `Ka=0`。

## 7. Emm42 执行接口

### 7.1 首选速度模式

本项目与项目一同为步进电机执行机构，优先使用：

```c
emm42_run_velocity(address, motor_rpm, acceleration, 0u);
```

控制器输出的摆杆角速度换算为电机 RPM：

```text
motor_rpm = motor_sign * omega_cmd * ratio / 6
```

其中：

- `ratio` 为实测 `电机角度变化 / 摆杆角度变化`；
- `6` 来自 `1 RPM = 6 deg/s`；
- `motor_sign` 只处理安装方向。

当前标定在水平附近的比值量级约为 `3.8 motor-deg / lever-deg`，但正式值必须在修正水平零位后重新测量。参考项目一的做法，允许使用抬升和下降两个常数传动比，不需要精确连杆公式。

### 7.2 速度模式准入测试

取下钢球，依次测试：

```text
motor_rpm = +/-1, +/-2, +/-5, +/-10, +/-20
```

每档检查启动、匀速、换向、零速停止和绝对位置变化。速度模式必须同时满足：

- 连续运行 60 s 无通信卡死；
- `1 RPM` 能产生可接受的连续运动，不出现明显走走停停；
- 正反向符号和速度比例一致；
- 零速命令能可靠停止继续累计位置；
- 换向不触碰机构间隙或机械限位；
- 位置反馈可在不阻塞速度命令的情况下稳定更新；
- 软件软限位能在两端阻止继续向外运动；
- 急停命令优先于普通速度命令。

通过后，后续闭环固定使用速度模式，不再同时调位置模式。

### 7.3 速度模式不通过时的唯一备选

若失败原因确定为 `1 RPM` 分辨率、低速抖动或驱动器速度模式本身，而不是程序调度问题，则使用：

```text
theta_target[k+1] = theta_target[k] + omega_cmd * dt
```

MCU 积分得到摆杆目标角，再发送 Emm42 绝对位置。此时：

- MCU 是唯一轨迹生成者；
- Emm42 内部加速度设置为能够跟随 MCU 目标；
- 不再叠加第二套 MCU 摆角限速器；
- 控制律和参数需要按位置执行接口重新验收。

速度模式和该备选方案禁止并行开发、混合发送或在一次实验中自动切换。

### 7.4 UART7 事务调度

现有 Emm42 接口在发送新命令前会处理或清理接收状态。新执行器模块必须保证同一时刻只有一个待应答事务。

事务优先级：

```text
急停/零速 > 速度变化命令 > 位置查询 > 普通保活
```

建议策略：

- 控制器每 20 ms 计算一次；
- RPM 量化值变化时发送速度命令；
- RPM 未变化时不重复刷相同命令，只做 100 ms 保活；
- 总线空闲时以 40~50 ms 周期查询绝对位置；
- 新事务必须等待上一事务完成或超时；
- 禁止为了发送下一命令直接丢弃尚未解析的上一帧；
- 位置反馈超过允许年龄时先退出闭环，再处理通信恢复。

## 8. 电机位置、零位和限位

### 8.1 上电流程

上电仍保留现有安全流程：

```text
去使能
-> 机械下限建立零位
-> 使能
-> 使用修正后的静态标定移动到物理水平
-> 确认位置反馈
-> 切入速度模式并等待视觉
```

物理水平对应的电机位置必须先统一为最新标定值。当前源码和测试存在的 `-18.922 deg` 与 `-20.6676 deg` 不一致必须在新控制器上机前解决。

### 8.2 控制期间

控制期间不再每拍由摆杆角反解电机绝对角。绝对位置只用于：

- 电机位置有效性判断；
- 左右运动方向的传动比选择；
- 软限位降速；
- 硬限位停机；
- 视觉失效后的慢速回水平；
- 遥测和故障诊断。

软限位区内只衰减“继续向外”的 RPM，向中心方向的 RPM 始终允许。越过硬限位立即发送零速并锁存故障。

## 9. 最小状态机与失效行为

新控制状态只保留：

```text
DISABLED
STARTUP_LEVEL
WAIT_VISION
ACTIVE
STATIC_LOCK
SAFE_RETURN
FAULT
```

不再把正常控制过程拆成 ACCEL、TRACK、BRAKE、OVERSPEED、CAPTURE 和 BREAKAWAY。

### 9.1 STATIC_LOCK

建议进入条件：

```text
|e| <= 2 mm
|v| <= 3 mm/s
连续 500 ms
```

进入后：

- 发送零 RPM；
- 冻结位置积分；
- 保持步进电机使能；
- 继续运行视觉观测器。

释放条件：

```text
|e| >= 4 mm 或 |v| >= 6 mm/s
```

STATIC_LOCK 只在基础闭环已经稳定后启用。首轮调参关闭该功能，以免掩盖慢漂移。

### 9.2 视觉失效

- 短时失效：立即发送零 RPM，不使用预测状态继续控制；
- 持续失效且电机位置有效：以不超过 `3~5 deg/s` 的摆杆速度缓慢回水平；
- 电机位置也无效：停止电机并进入 FAULT；
- 视觉恢复后连续 3 帧可信，重置观测器和积分，再进入 ACTIVE。

### 9.3 钢球边界

- 进入软边界时，强制目标位置为中心并禁止外向目标速度；
- 越过硬边界时停止正常试验，记录故障并由人工接管；
- 首版不重新引入复杂边缘预测或最大角抢救逻辑。

## 10. 建议模块划分

新路线应新建独立模块，不在旧 `balance_control.c` 上继续删改：

```text
src/middle/ball_state_observer.c/.h
    时间戳 Alpha-Beta、状态有效性、外推

src/middle/ball_velocity_controller.c/.h
    位置滞回、制动速度包络、Kv、后置 Ki/Ka

src/middle/balance_velocity_actuator.c/.h
    beam deg/s -> motor RPM、传动比、软限位、命令量化

src/app/balance_simple_app.c/.h
    启动、视觉、状态机、UART 事务和遥测编排
```

旧模块处理方式：

- `balance_control.c` 和 `ball_motion_profile.c` 保留作历史参考，但不编入新控制路径；
- 现有 `emm42`、`vision_link`、回零、安全和遥测底层继续复用；
- 新旧控制器使用互斥编译开关，任何构建只允许一个滚球控制入口；
- 不要求旧 V2 单测约束新控制器的内部实现。

## 11. 首轮建议参数

以下参数用于保守上机，不是最终值，也不能直接复制两个开源项目的无量纲参数：

| 参数 | 初始值 | 第一轮允许范围 | 说明 |
|---|---:|---:|---|
| 控制周期 | 20 ms | 固定 | 不因项目一为 10 ms 就立即提频 |
| `alpha` | 0.85 | 0.6~0.95 | Alpha-Beta 位置修正 |
| `beta` | 0.15 | 0.05~0.30 | Alpha-Beta 速度修正 |
| `e_on` | 4 mm | 3~6 mm | 位置修正启动 |
| `e_off` | 2 mm | 1~3 mm | 位置修正停止 |
| `Kp` | 0.5 1/s | 0.3~1.5 1/s | 位置到目标速度 |
| `Ki` | 0 | 保持 0 | MVP 禁用 |
| `v_max` | 15 mm/s | 10~30 mm/s | 初期先慢后快 |
| `a_envelope` | 0.02 m/s^2 | 0.01~0.08 m/s^2 | 越小越早限速 |
| `Kv` | 0.25 deg/mm | 0.10~0.80 deg/mm | 球速误差到摆杆角速度 |
| `omega_max` | 10 deg/s | 5~35 deg/s | 初期限制执行强度 |
| `k_near` | 0 | 0~1.0 | 基础闭环通过后再启用 |
| `Ka` | 0 | 保持 0 | 后置 A/B 项 |
| `ratio` | 约 3.8 | 实测 | 电机角/摆杆角 |
| 视觉超时 | 80 ms | 60~100 ms | 与实测帧率一致 |

`Kv` 使用 `deg/mm` 是为了现场读数直观；代码中可换算为 SI 单位，但配置名称必须带单位。

开源项目参数只能作为量级参考。相机坐标比例、摆杆长度、传动比和控制周期不同，禁止直接复制 `Kp=1.51`、`Kv=0.4` 等数值后判断路线成败。

## 12. 分阶段实施与准入门槛

### 阶段 0：清理基线

工作：

- 归档并关闭 V2 控制入口；
- 修正水平零位不一致；
- 确认新旧控制编译开关互斥；
- 保留急停、回零和机械限位。

通过标准：无球上电可重复回到物理水平，主机测试全绿。

### 阶段 1：速度执行器

工作：完成第 7.2 节速度模式测试和 UART7 事务调度。

通过标准：60 s 连续正反向测试无通信卡死、无越界、零速可靠、位置反馈持续有效。

### 阶段 2：视觉观测器

工作：电机保持零速，只记录原始位置、估计位置和估计速度。

通过标准：满足第 5.5 节全部条件。

### 阶段 3：纯速度阻尼

配置：

```text
x_ref 任意
v_ref = 0
Kp = Ki = Ka = k_near = 0
omega = Kv * v
```

手动轻推或释放钢球，只验证速度反馈方向和阻尼。

通过标准：打开 Kv 后的振荡衰减速度明显快于电机零速，且振幅不增长、电机不高频换向。

### 阶段 4：位置 P + 制动包络

启用 `Kp`、`v_max` 和 `a_envelope`，其余增强项保持关闭。

调参顺序固定：

```text
先 Kv
-> 再 Kp
-> 再 v_max
-> 最后 a_envelope
```

若过冲：先减小 `a_envelope` 或 `v_max`，不要立即增加多个 D 类参数。  
若回位过慢：先增加 `Kp`，确认不饱和后再增加 `v_max`。  
若出现高频摆动：降低 `Kv` 或检查速度噪声与电机换向，不调位置积分。

通过标准：左右各 10 次从 `+/-50 mm` 释放，至少 9 次进入 `+/-4 mm`，之后 5 s 不出现持续等幅振荡。

### 阶段 5：中心品质

根据现象一次只选一个功能：

1. 可重复过冲：启用近目标增阻尼；
2. 可重复静差：启用小 Ki；
3. 已稳定但电机抖动：启用 STATIC_LOCK；
4. 速度衰减仍不足且观测可信：A/B 测试 Ka。

禁止一次同时打开上述四项。

通过标准：完成第 14 节静态最终验收。

### 阶段 6：扩大范围和扰动

- 从 `+/-50 mm` 扩展到 `+/-80 mm`、`+/-100 mm`；
- 测试左右不对称；
- 测试轻微人工扰动；
- 测试视觉单帧丢失和短时断流；
- 测试不同电池电压。

任何一项失败都回到最近通过阶段，不增加新控制结构掩盖问题。

### 阶段 7：底盘运动前馈

静态验收后再加入车辆补偿。采用项目一的连续前馈，并吸收项目二的事件提前触发：

```text
任务状态机提前发出 START/STOP 事件
        |
        v
前馈状态 ARMED -> ACTIVE -> RETURNING
        |
        v
theta_ff = theta_baseline + clamp(Kff * a_vehicle, +/-theta_ff_max)
        |
        v
omega_ff = clamp(Kangle * (theta_ff - theta_measured), +/-omega_ff_max)
        |
        v
omega_cmd += omega_ff * position_scale
```

其中：

```text
position_scale = clamp(1 - |e| / e_ff_cutoff, 0, 1)
```

前馈加速度优先使用底盘规划器已知的 `planned_accel_mps2` 以获得提前量，IMU 用于校正实际偏差。第一版前馈角限幅不超过 `1 deg`，验证后再逐步放宽到 `2~3 deg`。

禁止使用固定 `30 deg / 250 ms` 一类动作。

每个控制拍至少记录：


后置功能启用后再追加 `integral_output`、`filtered_ball_accel` 和车辆前馈字段。

主机单测至少覆盖：

- Alpha-Beta 正常更新、重复时间戳、回绕、重启和超时；
- 制动速度包络随距离单调且有限；
- 左右位置和速度输入的输出严格对称；
- 位置滞回不抖动；
- 饱和时积分抗饱和；
- 近目标增阻尼只在接近目标时启用；
- RPM 换算、量化和正负方向；
- 电机软限位只阻止向外运动；
- 视觉或电机反馈失效时输出归零；
- STATIC_LOCK 进入和释放滞回。

## 14. 静态最终验收标准

在底盘静止、车辆前馈关闭的条件下：

| 指标 | 要求 |
|---|---|
| 初始位置 | `+/-50 mm`、`+/-80 mm`，最后扩展到 `+/-100 mm` |
| 每个方向试验次数 | 至少 10 次 |
| 成功率 | 每个方向至少 9/10 |
| 到位条件 | `|e| <= 4 mm` 且 `|v| <= 5 mm/s` |
| `+/-50 mm` 到位时间 | 不超过 4 s |
| `+/-100 mm` 到位时间 | 不超过 7 s |
| 到位后保持 | 连续 10 s 不离开 `+/-6 mm` |
| 显著中心穿越 | 到位前最多 1 次越过对侧 `6 mm` |
| 持续振荡 | 不允许等幅或增幅振荡 |
| 电机行为 | 不长期饱和，不持续高频换向，不触发软限位 |
| 视觉短时丢帧 | 输出归零或安全回水平，不使用失真预测继续控制 |
| 通信与故障 | 无 UART 卡死、无未处理应答、无越界 |

验收必须同时保存原始日志。肉眼观察“这次好像停住”不能作为通过依据。

## 15. 调试纪律

后续调试固定遵守：

1. 每次只改变一个参数或启用一个功能。
2. 每组参数左右方向各做相同次数试验。
3. 参数文件中名称必须带单位。
4. 未通过当前阶段，不提前加入下一阶段功能。
5. 不根据单次成功结果提交参数。
6. 不用积分补偿错误水平零位。
7. 不用 Ka 掩盖速度估计噪声。
8. 不用更大摆角掩盖执行器通信或换向问题。
9. 不因视觉只有约 39 Hz 就伪造 200 Hz 新测量。
10. 不把开源项目参数原值当成本机标定值。

## 16. 路线总结

本路线的核心不是复制某个 PID 参数，而是复制项目一已经验证过的控制职责划分：

```text
时间戳解决视觉时间问题
位置外环只决定球应该多快
速度反馈只决定摆杆应该怎样动
步进电机速度模式直接执行摆杆运动
绝对位置反馈负责安全，而不是承担钢球精确逆解
```

项目二贡献的是比赛工程经验：越接近目标越需要阻尼，到位必须同时检查位置和速度，已知起步/停车事件应提前通知前馈。但这些经验只以连续、可限幅、可关闭的形式加入。

第一目标是获得一个简单、可重复、可解释的静态闭环。只有该闭环通过日志验收后，才允许增加积分、加速度阻尼和车辆前馈。

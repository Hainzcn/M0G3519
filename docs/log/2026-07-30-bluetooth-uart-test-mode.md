# 任务日志：蓝牙 UART 测试模式

日期：2026-07-30

## 变更

- 新增 UART3，PB12 为 TX、PB13 为 RX，通信参数为 115200-8-N-1。
- 新增蓝牙 RX 中断缓冲和非阻塞 TX 缓冲。
- 新增上电蓝牙测试应用：启动提示、1Hz 在线提示和字节回显。
- 上电保持电机停机，不初始化或运行循迹、IMU、OLED 和 Emm42 demo。
- 关闭循迹与圆周 demo 的自动启动宏。

## 接线

| 蓝牙模块 | MSPM0G3519 |
| --- | --- |
| RX | PB12 / UART3 TX |
| TX | PB13 / UART3 RX |
| GND | GND |

UART 逻辑电平必须兼容 3.3V。手机或电脑连接蓝牙串口后，应周期性收到 `[bt] alive`；发送任意内容后应收到完全相同的回显。

> 2026-07-31：该回显测试模式已由视觉通信MVP取代。当前固件输出`[link] alive`，
> UART3 RX字节进入24字节视觉解析器，不再回显；本页仅保留历史测试记录。

# 2026-08-01 摆杆轨迹与动态前馈重构

## 原因

生产参数中的固定 `10mm` 制动裕量会让参考轨迹提前刹停，随后在 200Hz 下反复进入
加速和制动。旧参数仿真中，单次 `O -> +5cm` 需要约 `6.2s`，已经超过完整往返
`4.8s` 的软件超时。

同时，滚球控制器虽然具有车辆加速度输入，应用层却固定传入零；50Hz 外环结果最终
只以 10Hz 发送给 Emm42，无法用于整车稳定启停。

## 修改

- 删除球参考轨迹的固定制动距离裕量，按理论制动距离切换并锁存制动阶段。
- 生产轨迹改为 `0.12m/s^2` 驱动、`0.16m/s^2` 制动、`0.075m/s` 限速。
- 参考加速度前馈增益改为 `1.0`，位置/速度反馈起始值改为 `Kp=8`、`Kd=4`。
- Emm42 变化目标刷新周期由 `100ms` 改为 `20ms`；未变化目标仍不重复发送。
- 接入轮速控制器的规划加速度，提供独立符号、增益和 `2m/s^2` 限幅。
- 主循环先更新轮速控制，再运行摆杆控制，避免使用上一控制周期的规划加速度。
- 使用视觉 `processing_ms` 和 `3ms` 传输估计补偿测量年龄，并按测量速度前推位置。
- 轨迹测试改为直接引用生产参数，检查耗时、位置单调性和阶段切换次数。
- Demo 测试不再硬编码旧启动限位对应的电机绝对角。

## 上车前验证顺序

1. 取下钢球，确认 50Hz 连续目标不会导致 Emm42 丢应答、重复启停或异常噪声。
2. 脱开底盘电机或架空车轮，确认正向规划加速度对应的摆杆前馈方向正确。
3. 底盘静止，只做中心扰动恢复，记录视觉位置、速度、摆杆目标和实际角。
4. 完成 `O -> +5cm -> -5cm`，确认总时间小于 `4.5s` 且末端稳定误差小于
   `8mm`，连续重复至少 10 次。
5. 使用低底盘加速度执行直线启停，再逐级提高到比赛速度；任何一级球位置峰值超过
   `10mm` 都不得继续提高。

摆杆 IMU 尚未完成方向、比例、零偏和线性加速度影响标定，本次不将其直接接入闭环。

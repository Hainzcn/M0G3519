# 双侧摆杆偏置设计与标定

## 设计目标

原控制器在球状态换算出的目标摆角上统一增加
`BALANCE_SIMPLE_FIXED_BEAM_BIAS_DEG`。当偏置为正时，它会增大正向目标摆角，
同时减小负向目标摆角的绝对值，因此无法独立补偿摆杆两侧的机械、摩擦和传动差异。

新设计按照“加偏置前目标摆角”的方向分别应用正侧和负侧偏置。选择依据不是球位置，
也不是当前实测摆角，避免球越过目标点或摆杆姿态滞后时选错参数。

## 换算公式

加偏置前的目标摆角为：

```text
theta_0 = K_v * (v - v_target) + K_a * a_ball + theta_vehicle_ff
```

定义正侧偏置 `b_pos`、负侧偏置 `b_neg` 和过零混合半宽 `delta`：

```text
w_pos = clamp((theta_0 + delta) / (2 * delta), 0, 1)
b = b_neg + (b_pos - b_neg) * w_pos
theta_target = clamp(theta_0 + b, -theta_max, theta_max)
```

当 `theta_0 >= delta` 时，偏置严格等于 `b_pos`；当 `theta_0 <= -delta` 时，
偏置严格等于 `b_neg`；中间区域连续插值，防止摆杆经过零点时出现目标摆角阶跃。

## 配置参数

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| `BALANCE_SIMPLE_POSITIVE_BEAM_BIAS_DEG` | `+0.2 deg` | 正侧修正量 |
| `BALANCE_SIMPLE_NEGATIVE_BEAM_BIAS_DEG` | `+0.2 deg` | 负侧修正量 |
| `BALANCE_SIMPLE_BEAM_BIAS_BLEND_ANGLE_DEG` | `0.2 deg` | 零点连续混合半宽 |

两侧默认值均沿用旧参数，因此更新固件后初始控制行为不变。运行时调节值会跨
`balance_simple_app_init()` 保留，但当前仍不写入掉电存储；确定最优值后应同步修改配置宏。

## 现场调节

在主菜单长按 SW1 进入 `BEAM BIAS TUNE`：

- SW3：选择 `POS` 或 `NEG`，`>` 指示当前侧。
- SW1：当前侧减少 `0.2 deg`。
- SW2：当前侧增加 `0.2 deg`。
- SW4：返回主菜单。

建议保持正侧 `+0.2 deg` 不动，先将负侧由 `+0.2 deg` 调到 `0.0 deg` 复测。
若负侧仍欠位，再以 `0.2 deg` 为步长向负值调节。每次应在相同目标位置、相同初始球位、
底盘静止和视觉稳定的条件下比较稳态误差、首次到达时间和最大超调，避免仅凭单次结果选值。

如果两侧最优偏置相差较大且中心附近出现来回动作，可将混合半宽从 `0.2 deg`
提高到 `0.3-0.4 deg` 后复测。偏置只能补偿方向相关的静态误差；若同一侧误差还随摆角幅值
明显变化，下一步应升级为正负侧独立增益或分段标定表，而不是继续增大常量偏置。

# 摆杆控制系统 V1

## 1. 当前范围

V1 的基础闭环用于将钢球稳定在摆杆目标位置；底盘运动时可启用编码器前馈 Demo。
控制链路为：

```text
视觉 24B 状态帧 -> 延迟补偿 -> 200Hz 状态估计/PD -> 摆杆角逆动力学
                  -> 连杆逆解 -> 50Hz Emm42 绝对位置命令
```

左右轮编码器的有符号平均速度经差分和低通后得到车辆实测加速度，并在进入控制器前
执行符号、单位增益和 `2m/s^2` 限幅。控制器按无相对运动条件计算同步角
`-atan2(a_car, g)`，再叠加视觉位置闭环修正；闭环进入
`ACTIVE` 后默认回中，按下 `SW1` 启动 `O -> +5cm -> -5cm -> 保持` 流程。
V1 不启用积分。SW2/SW3 联合控制 Demo 不依赖 IMU；详细操作见
[小车运动编码器前馈Demo.md](小车运动编码器前馈Demo.md)。

轨迹规划器以 200Hz 运行，维护 `x_ref/v_ref/a_ref`。它根据参考速度计算制动距离
`v_ref^2/(2*a_brake)`，在剩余距离进入制动区时反向加速度，并将三项参考量送入：

```text
a_cmd = a_ref + Kp*(x_ref-x_est) + Kd*(v_ref-v_est)
```

默认轨迹加速度为 `0.12m/s^2`、制动加速度为 `0.16m/s^2`、最大速度为
`0.075m/s`。制动切换只使用 `v_ref^2/(2*a_brake)`，进入制动阶段后保持制动，
禁止重新进入主加速阶段。轨迹加速度前馈系数为 `1.0`，总加速度仍限制在
`0.45m/s^2`。生产参数下参考轨迹 `O -> +5cm` 约 `1.21s`、`+5cm -> -5cm`
约 `1.88s`，加上中间确认后约 `3.2s`，给实球末端捕获保留约 `1.6s`。参考轨迹
到达目标时速度严格归零；
实球同时满足位置误差不超过 `6mm`、速度不超过 `0.03m/s` 并保持 `100ms` 后，
流程才确认到达。完整往返超过 `4.8s` 会取消并回中。

## 2. 上电前必须完成的标定

固件默认：

```c
#define BALANCE_STARTUP_CALIBRATED      (0u)
#define BALANCE_STARTUP_LEVER_ANGLE_DEG (-5.0f)
```

`-5.0f` 只是不可使能状态下的占位值。实测机械负角限位相对水平的角度后，填写真实
负角并把 `BALANCE_STARTUP_CALIBRATED` 改为 `1u`。修改前固件保持
`UNCONFIGURED`，只初始化 UART7，不使能或移动 Emm42。

首次启用必须取下钢球或脱开连杆，确认以下方向：

1. 机构每次上电都可靠停在同一个负角机械限位；
2. 程序将限位设为电机零点后，水平目标不会经过机构死点或机械限位；
3. 球位置为正时，控制器输出正摆杆角，即车头端抬高；
4. Emm42 位置反馈与电机目标角同号且误差逐步缩小。

当前机构中 Emm42 负轴角使摆杆从最低位上抬，因此
`BALANCE_EMM42_DIRECTION_SIGN=-1`。实测逻辑正摆杆角与连杆模型目标轴相反，因此
`BALANCE_LINKAGE_TARGET_SIGN=-1`；该符号只作用于水平附近的目标角，不改变已标定的
最低位启动参考角。

闭环实测中，球位于管后端时原控制目标会让摆杆继续上抬，因此闭环执行方向使用
`BALANCE_CONTROL_OUTPUT_SIGN=-1` 反转。该符号不影响回水平和正负 5 度 Demo。
车辆前馈方向由 `BALANCE_CAR_IMU_ACCEL_SIGN` 统一配置：IMU 正向加速度时，
必须先脱开连杆或取下钢球，确认前馈摆角方向能够抵消钢球相对车体的惯性运动。

## 3. 状态机和失效行为

`POWER_WAIT` 等待驱动器上电 3 秒后，先明确去使能并等待摆杆靠重力落到机械最低位
1.5 秒，再依次执行当前位置置零、重新使能、回水平和位置反馈确认。这样即使上一次
运行结束时 Emm42 仍保持使能，MCU 再次启动也能重新建立相同的最低位参考。进入
闭环以 50Hz 更新发生变化的 Emm42 目标，并以 10Hz 查询当前电机轴角；摆杆 V2
调试遥测仍以 100Hz 发送，
两次查询之间复用最近一次有效电机轴角。水平误差小于 `1deg` 并保持 200ms 后进入
`WAIT_VISION`，保持水平目标；连续 5 帧同时满足有效位、跟踪器就绪、标定有效且
置信度不低于 50 后才进入 `ACTIVE`。任一不合格状态帧会清零连续帧计数。每条命令
必须在 25ms 内收到正确应答，连续 3 次失败锁存故障。电机目标与位置反馈的误差
允许短时超过 `5deg`；只有持续超过 1 秒才按电机跟随故障锁存，避免碰壁反向时的
正常动态滞后被误判为堵转。

- 有效测量年龄不超过 30ms：正常位置/速度反馈；
- 30~80ms：仅模型预测，摆杆角限制收紧为正负 2deg；
- 超过 80ms 或链路离线：进入 `RECOVERY` 并限速回水平；
- 自动往返期间进入 `RECOVERY` 或故障：立即取消流程，目标改回中心；
- 恢复后连续 5 帧满足有效位、跟踪器就绪、标定有效且置信度不低于 50，重新进入
  `ACTIVE`；
- 球位置超过正负 100mm：强制边缘恢复；超过正负 125mm 持续 200ms 锁存故障。

有效测量年龄包含视觉帧上报的处理耗时和默认 `3ms` 串口传输补偿，最多补偿
`30ms`。新测量位置按视觉速度前推到控制时刻；两颗处理器的绝对毫秒时间戳不直接
相减。

故障锁存后发送一次 Emm42 停止命令，本次上电不自动恢复。

## 4. 台架调试

将 `UART3_MAIX_MODE` 切换为 `UART3_MAIX_MODE_BALANCE_TELEMETRY_DEBUG`，使用
MaixCAM2 原始日志接收器采集数据，再运行：

```powershell
python .\tools\balance_log\analyze_balance_log.py .\log\session_xxxxxxxx_xx
```

调参顺序固定为编码器方向与加速度滤波、执行延迟和限幅、`Kp`、`Kd`、估计器校正增益。
当前起始值为 `Kp=8`、`Kd=4`；V1 验收前保持 `Ki=0`。
完成调试后恢复 UART3 正常模式，确保 MCU 到 MaixCAM2 的 TX 方向静默。

正常模式下 UART0 每秒额外输出一条 `[balance]`：`raw` 为视觉原始状态位，
`conf` 和 `seq` 分别显示最近接受值/原始值，`st` 为摆杆状态机。该诊断不使用
UART3 TX。新增的 `tgt`、`ref`、`ph` 和 `seqst` 分别表示目标位置、参考位置/速度、
轨迹阶段和往返流程状态。

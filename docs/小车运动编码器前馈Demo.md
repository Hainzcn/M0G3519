# 小车运动 IMU 前馈 Demo（编码器对照）

## 1. 控制原理

运行时近似认为钢球相对摆杆静止，与小车具有相同的纵向有效加速度。前馈直接使用
ATK-MS901M 的车体 X 轴加速度；模块上电配置为 100 Hz、±4 g，并仅回传姿态和
加速度/陀螺帧。MCU 不再叠加低通，只做零偏、增益、方向、新鲜度和安全限幅：

```text
a_car = clamp((imu_ax - offset) * gain * sign, +/-2 m/s^2)
valid = ACCEL frame received && sample_age <= 25 ms
```

这里使用的是车体纵轴上的比力，它同时反映平动惯性和车体小俯仰造成的重力投影，
正是摆杆相对车体需要抵消的有效加速度；不要在本路径中再次按 pitch 去重力。安装
必须满足 IMU X 轴沿车头方向，静止时用 `BALANCE_CAR_IMU_ACCEL_OFFSET_MPS2` 扣零偏。

在小车加速参考系内，钢球沿杆方向保持静止时有：

```text
m * g * sin(theta) + m * a_car * cos(theta) = 0
theta_sync = -atan2(a_car, g)
```

质量 `m` 被约去，因此同步前馈不需要球质量、滚球惯量或额外动力学标定。视觉位置
闭环仍计算钢球相对摆杆所需的修正加速度，并围绕 `theta_sync` 叠加修正角。最终摆
杆角继续通过现有连杆反解换算为 Emm42 绝对电机角。

## 2. 操作

1. 上电后等待平衡状态进入 `ACTIVE`，确认钢球视觉位置有效且底盘停止。
2. 按 `SW2`：目标设为中心点 O，并开始循迹一圈。
3. 按 `SW3`：锁定按键瞬间的钢球位置并循迹一圈，目标必须在 `+/-9 cm` 内。
4. 按 `SW4`：立即停止底盘，滚球闭环继续保持本次目标位置。

累计里程达到 4.5 m 后才允许识别 A 点横线；横线连续有效 20 ms 后停车。运行超过
30 s，或平衡失效、循迹连续丢失 500 ms、IMU 连续无新鲜数据 100 ms 时自动停车。
IMU 数据超过 25 ms 时前馈立即归零，不会沿用旧加速度；编码器加速度只保留为遥测
对照。启动 demo 前也必须先有新鲜 IMU 数据。

## 3. 传感器选择

编码器路径以 10 ms 整数 RPM 求速度，再差分并经过 `alpha=0.20` 一阶低通：轮速
窗口/差分约 10 ms，低频群延迟约 40 ms，合计约 50 ms，且手拖低速时量化明显。
IMU 为 100 Hz，UART 115200；DMA 块从 64 字节缩为 16 字节后，MCU 侧典型延迟约
6~8 ms，明显低于编码器路径。因此控制选择 IMU，编码器只用于对比和实车互相关
复核。模块内部滤波延迟仍需用同一次推车脉冲实测确认。

## 4. 调试输出

UART0 每 50 ms 输出：

```text
[car-ff] imu=IMU原值,age=数据年龄,enc=编码器滤波加速度,ff=限幅后加速度,sync=同步摆角,raw=闭环摆角,m=电机目标,ok=有效位
```

正向加速时，默认 `imu` 和 `ff` 为正，`sync` 为负，即车头端降低。若 IMU 安装方向
与该约定相反，只修改 `BALANCE_CAR_IMU_ACCEL_SIGN`。首次检查应取下钢球或脱开
连杆，确认方向后再装球运行。若 `ok=0` 或 `age>25`，先检查模块报告率、接线和 DMA
溢出，不要放宽新鲜度后继续使用旧数据。

实车调试先检查 `imu` 与启停方向，再调整 IMU 模块自身带宽和零偏。不要给前馈额外
叠加低通，也不要通过修改物理反解公式放大角度；振动过大时优先处理安装刚度和模块
带宽。

# 灰度查表循迹与双轮速度 PID 框架

本文说明当前 MSPM0G3519 底盘控制框架、启用方法和首轮调参顺序。动力学和前馈公式见 [formula.md](formula.md) 第 8 节。

## 1. 控制结构

```text
八路灰度数字量（黑线=1）
  -> 8 位位型 + 离散位置查表
  -> 直道/右半圆编码器里程状态 + 分级降速
  -> 左右轮目标 RPM
  -> 左右轮独立 PID + kS/kV/kA 前馈
  -> TB6612 PWM
  -> 编码器 100 Hz 反馈
```

控制周期为 10 ms。灰度扫描仍在主循环非阻塞运行，控制器通过扫描序号判断是否获得新数据。编码器测速由轮速控制器独占，1 Hz 心跳只读取结果，不再改变测速采样基准。

## 2. 文件与职责

| 文件 | 职责 |
| --- | --- |
| `src/middle/control_config.h` | 控制周期、符号、限幅和初始增益 |
| `src/middle/control_pid.c/.h` | 带条件积分抗饱和的通用 PID |
| `src/middle/line_control.c/.h` | 黑线位型查表、胶囊赛道阶段、丢线搜索和差速目标 |
| `src/middle/wheel_speed_control.c/.h` | 双轮速度 PID 和电机前馈 |
| `src/app/motor_app.c/.h` | 100 Hz 调度、模式、安全停止和遥测 |

## 3. 运行模式

当前 `MOTOR_APP_AUTO_START_LINE_FOLLOW=1`，上电自动从胶囊赛道直道阶段开始循迹。
起点必须位于直道起点附近；若从右半圆起步，将 `LINE_LOOKUP_INITIAL_PHASE` 设为 `1`。

架空轮速标定：

```c
motor_app_set_speed_test(50.0f, 50.0f);
```

落地循迹：

```c
motor_app_set_base_rpm(60.0f);
motor_app_set_line_follow_enabled(1u);
```

任何阶段停止：

```c
motor_app_stop();
```

车体参数验证用顺时针 1 m 直径圆 demo：

```c
motor_app_set_right_circle_demo(120.0f);
```

也可将 `MOTOR_APP_AUTO_START_LINE_FOLLOW` 设为 `0`、
`MOTOR_APP_AUTO_START_RIGHT_CIRCLE_DEMO` 设为 `1`，使其上电自动运行。
按轮距 0.195 m、轮径 0.065 m 计算，中心目标 120 RPM 时左右轮目标分别为
143.4 RPM 和 96.6 RPM，中心线速度约 0.408 m/s，理论单圈约 7.70 s。

这些入口后续应由比赛状态机调用，不应长期硬编码在 `main()` 中。

## 4. 灰度位型查表

模块原始数字量定义为 `1=黑线、0=白色地图`。通道 `i` 检测到黑线时，
`sensor_mask` 的 bit `i` 置 1。控制器只接受单个黑点以及连续 2~5 个黑点的位型，
查表得到 -4..+4 的离散位置等级；`0x18` 和 `0x3C` 视为居中。

位置等级经过最近三个有效样本的中值滤波，再映射为 0、8、16、28、42 RPM
的离散修正。通道 7 方向默认产生正修正，即左轮加速、右轮减速；若实车方向相反，
只把 `LINE_LOOKUP_CORRECTION_SIGN` 改为 `-1.0f`。

上述数值以 `LINE_LOOKUP_SPEED_REFERENCE_RPM=120 RPM` 为固定标定基准。修改
`LINE_LOOKUP_STRAIGHT_BASE_RPM` 可设置上电默认速度，也可通过
`motor_app_set_base_rpm()` 设置运行时速度。控制器自动计算
`k=新中心速度/120`。直道、过渡区和圆弯使用同一个中心 RPM，几何曲率差速按
实际速度线性换算；这部分必须保持线性才能维持 0.5 m 转弯半径。离散查表反馈
使用独立比例 `h`：低于 120 RPM 时同比缩小，高速时限制在
`LINE_LOOKUP_FEEDBACK_SCALE_MAX=1.00`，避免灰度采样、电机和车体带宽未提高却继续
放大纠偏。位型到位置等级的表与速度无关，因此调速不需要重写查表。允许的中心
速度范围为 60~180 RPM，超出时自动限幅。

控制器分别对中心速度和转向差速做斜率限制，再由
`left=base+turn`、`right=base-turn` 生成轮速。因此启动完成后，无论阶段和误差
如何变化，左右目标平均值都严格等于设置速度；纠偏和弯道前馈不会产生计划纵向
加速度。等级反向时先逐级回零并保持 40 ms，再允许建立反向纠偏，抑制离散查表
从负大误差直接跳到正大误差造成的摆动。

## 5. 胶囊赛道阶段与丢线

控制器从直道阶段起步，使用双轮编码器平均里程交替运行：

```text
STRAIGHT  1.500 m -> RIGHT_ARC 1.5708 m -> STRAIGHT -> ...
```

直道和右半圆使用同一个中心目标。轮距 0.195 m、圆弧半径 0.5 m，因此圆弯居中
时右转差速为 `base*0.195/(2*0.5)`；中心目标 170 RPM 时差速为 33.15 RPM，
左右目标约 203.2/136.9 RPM。查表修正叠加在这个稳定差速上，不再由瞬时右侧
探头开关曲率前馈。

直道与圆弧边界两侧各设置 `LINE_LOOKUP_TRANSITION_HALF_LENGTH_M=0.15 m` 的
smoothstep 过渡区。进弯时曲率因子在切换点前 0.15 m 从 0 增至 0.5，切换后
0.15 m 从 0.5 增至 1；出弯时对称降至 0。该因子只平滑转向差速，中心速度不变。

无有效位型或检测到不少于 6 路黑线时：有历史位型则保持 80 ms；随后保持当前
中心速度并叠加右转搜索差速。累计 250 ms 仍未恢复才置位丢线并停车。灰度扫描
超过 30 ms 不更新仍由应用层立即安全停止。

## 6. 双轮速度环

每侧输出实现 `formula.md` 中的电机模型：

$$
u_m=k_S\operatorname{sgn}(n_r)+k_Vn_r+k_A\dot n_r
+K_p(n_r-n)+K_i\int(n_r-n)dt+K_d\frac{d(n_r-n)}{dt}
$$

电机标称最高转速为 **320 RPM**（`MOTOR_RATED_MAX_RPM`）。满 PWM 架空实测左轮约 305 RPM、右轮约 330 RPM，分别记录在 `WHEEL_LEFT_MEASURED_MAX_RPM` 和 `WHEEL_RIGHT_MEASURED_MAX_RPM`。软件目标暂时限制为 250 RPM，供 $k_A$ 使用的目标加速度估计限制为 600 RPM/s，PWM 限制为 10000。

PID 输出先经过左右独立映射：左轮 `WHEEL_LEFT_PWM_MAP_SCALE=1.00`，右轮 `WHEEL_RIGHT_PWM_MAP_SCALE=0.92`，因此右轮最大物理 PWM 为 9200，理论空载最高转速约为 304 RPM。正反转共用同一比例。映射后再经过 `WHEEL_PWM_SLEW_DUTY_PER_S` 限制；默认 30000 duty/s，即 10 ms 内最多改变 300，防止新的灰度状态把阶跃电压直接施加到电机。安全停机不经过该限制。输出饱和且误差继续推动饱和时暂停积分。

## 7. 必做符号检查

修改 `control_config.h` 前先架空车轮：

1. 确认 PWMA/PWMB 分别驱动物理左/右轮；若接线暂时相反，设置 `MOTOR_OUTPUT_SWAP_LEFT_RIGHT=1`。
2. 分别给左右轮正目标，确认两轮都向车辆前进方向转；反转侧将 `MOTOR_LEFT_OUTPUT_POLARITY` 或 `MOTOR_RIGHT_OUTPUT_POLARITY` 改为 `-1`。
3. 正转时串口 `m=` 后对应实测 RPM 必须为正；否则修改 `WHEEL_LEFT_ENCODER_SIGN` 或 `WHEEL_RIGHT_ENCODER_SIGN`。电机输出极性和编码器计数极性必须分别校准。
4. 将黑线依次移到通道 0 和通道 7，确认 `e=` 分别为负和正。
5. 在线位于车体右侧时，确认控制器使车辆向右修正。
6. 若黑线没有被判为有效，切换 `LINE_SENSOR_ACTIVE_LEVEL`，不要先调 PID。

## 8. 调参顺序

### 8.1 单轮开环辨识

暂时令轮速 PID 增益为零，逐级增加 PWM，记录每侧启动占空比和稳态 RPM：

- 启动占空比估计 $k_S$。
- 稳态 PWM-RPM 斜率估计 $k_V$。
- 左右轮分别辨识，不能直接共用参数。

### 8.2 架空轮速闭环

1. 先设 `kS/kV`，`Ki=Kd=0`，从小到大增加 `Kp`。
2. 能快速跟随且无持续振荡后，加入小 `Ki` 消除静差。
3. 一般不需要轮速 `Kd`；编码器 10 ms 计数分辨率有限，微分容易放大噪声。
4. 分别测试 30、60、100 RPM 和正反向阶跃。

### 8.3 落地直线

先只验证双轮速度环。使用相同目标 RPM，分别修正左右 `kV` 或速度环增益，保证直线不持续偏航。

### 8.4 查表循迹

1. 从直道起点低速启动，确认 `q=08/10/18` 等位型与实车黑线位置一致。
2. 黑线移到通道 7 时应使左目标高于右目标；方向相反就翻转 `LINE_LOOKUP_CORRECTION_SIGN`。
3. 固定直道低速检查 8、16、28、42 RPM 四级修正，不先提高基础速度。
4. 固定右半圆检查 `b` 对应的几何差速；居中时应稳定维持右转，不依赖查表误差触发。
5. 最后校准 1.5 m/1.5708 m 的里程切换点，再逐步提高直道和圆弧基础 RPM。

## 9. 串口遥测

UART0 调试口在活动模式下每 250 ms 输出原有文本摘要：

```text
[ctl] mode,v=<直道RPM>,k=<速度比例千分比>,h=<反馈比例千分比>,q=<位型>,p=<0直道/1右弧>,d=<阶段mm>,g=<曲率千分比>,e=<等级x1000>,n=<黑线数>,c=<查表修正>,b=<弧线基准差速>,t=<目标>,m=<实测>,u=<PWM>,s=<饱和>
```

UART3（PB12/PB13，115200-8-N-1）每 100 ms 发送固定 52 字节
`0x81 CHASSIS_TELEMETRY` 二进制帧，包含车辆模式/标志、规划速度和加速度、左右
目标/实测 RPM、左右前馈/反馈/最终 PWM、实测前进速度和加速度、循迹误差及 UART
丢弃计数。完整字段与解析规则见 [UART3底盘遥测协议.md](UART3底盘遥测协议.md)。

调参时重点观察目标与实测方向是否一致、PWM 是否长期饱和、左右轮稳态误差是否
不同。正式比赛前应关闭 UART0 文本摘要；UART3 定长二进制帧可以保留用于车载记录。

## 10. 后续工作

- 用实测数据填写左右轮 `kS/kV/kA` 和 PID 增益。
- 若后续需要更高车速，用加速度、加加速度受限的 S 曲线规划器替代当前一阶斜率限制。
- 将 `marker_detected` 接入 A 点检测和停车状态机。
- 将阶段、位型和查表等级加入下一版二进制遥测协议。
- 将车体规划加速度输出给滚球摆杆前馈。

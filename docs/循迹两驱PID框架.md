# H题六路查表循迹框架

本文说明 H 题“直线 + 两段半圆弧”黑色环形赛道的底盘循迹控制。循迹仅使用六路红外模块，满足题目限制；滚球相机不参与路线识别。

## 控制结构

```text
六路红外数字状态
  -> 6 bit 状态码（0~63）
  -> 查表转向档位（-4~+4）
  -> 左右轮目标 RPM + 目标斜坡
  -> 左右轮独立速度闭环和电机前馈
  -> TB6612 PWM
  -> 编码器反馈
```

`src/middle/line_control.c` 中的 `line_turn_lookup` 由完整六位状态码索引。X1 是车辆左侧、X6 是车辆右侧；负档位向左修正，正档位向右修正。若上板后的实际转向相反，应交换表项符号或确认左右电机正向，不能仅修改一个轮子的编码器符号。

赛道仅有 A 点的一条横向启停线，因此五路或六路同时检测到黑线时会置位 `marker_detected`，并将转向档位置零，使车辆直行通过该线。A 点计圈、减速和停车由比赛状态机根据该标志和编码器里程实现，不能靠固定延时。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `src/middle/control_config.h` | 查表差速档位、弯道降速、目标斜坡和安全阈值 |
| `src/middle/line_control.c/.h` | 六路状态压缩、查表、丢线保护与目标 RPM |
| `src/middle/wheel_speed_control.c/.h` | 双轮速度闭环和电机前馈 |
| `src/app/motor_app.c/.h` | 100 Hz 调度、扫描超时保护与遥测 |

## 运行和调参

默认调用：

```c
motor_app_set_base_rpm(60.0f);
motor_app_set_line_follow_enabled(1u);
```

每个状态表项先乘以 `LINE_TABLE_TURN_RPM_STEP`，再受最小内轮转速限制。转向等级越大，基础速度按 `LINE_TABLE_CURVE_RPM_REDUCTION` 降低；最后由 `LINE_TARGET_SLEW_RPM_PER_S` 平滑目标变化。

六路状态须连续两帧（5 ms 间隔）一致才会发布给控制器，滤除单帧红外抖动；若有效位之间出现空洞，例如 `X1` 与 `X6` 同时有效而中间无效，则按短时丢线处理，保持上一有效方向而不采用该异常状态查表。

按以下顺序调试：

1. 架空确认两轮给定正 RPM 时均向前，且编码器 RPM 为正。
2. 依次将黑线放在 X1、X3/X4、X6，确认车辆分别向左、直行、右修正；方向错则整体翻转表项符号。
3. 低速跑半圆弧。回线太慢时增加 `LINE_TABLE_TURN_RPM_STEP`；蛇形时减小该值或降低 `LINE_TARGET_SLEW_RPM_PER_S`。
4. 再提高 `LINE_BASE_RPM_DEFAULT`。该值必须根据车轮周长和实测地速计算，满足题目时限前先验证滚球稳定性。

安全策略：无有效探头时保持最近转向方向最多 `LINE_LOST_HOLD_MS`，随后停车；扫描序号 30 ms 未更新时由 `motor_app` 停车。查表仅输出轮速目标，绝不直接输出 PWM。

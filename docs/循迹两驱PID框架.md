# 循迹两驱 PID 框架

本文说明当前 MSPM0G3519 底盘控制框架、启用方法和首轮调参顺序。动力学和前馈公式见 [formula.md](formula.md) 第 8 节。

## 1. 控制结构

```text
八路灰度数字量
  -> 加权位置误差、丢线和横线检测
  -> 循迹 PID + 弯道降速
  -> 左右轮目标 RPM
  -> 左右轮独立 PID + kS/kV/kA 前馈
  -> TB6612 PWM
  -> 编码器 100 Hz 反馈
```

控制周期为 10 ms。灰度扫描仍在主循环非阻塞运行，控制器通过扫描序号判断是否获得新数据。编码器测速由轮速控制器独占，1 Hz 心跳只读取结果，不再改变测速采样基准。

## 2. 文件与职责

| 文件 | 职责 |
| --- | --- |
| `src/middle/control_config.h` | 控制周期、符号、限幅和初始增益 |
| `src/middle/control_pid.c/.h` | 带条件积分抗饱和的通用 PID |
| `src/middle/line_control.c/.h` | 八路加权误差、丢线、横线、差速目标 |
| `src/middle/wheel_speed_control.c/.h` | 双轮速度 PID 和电机前馈 |
| `src/app/motor_app.c/.h` | 100 Hz 调度、模式、安全停止和遥测 |

## 3. 运行模式

当前无用户按键，`MOTOR_APP_AUTO_START_LINE_FOLLOW=1`，上电取得第一帧有效灰度数据后自动进入循迹。将该宏改为 `0` 可恢复上电禁用。

架空轮速标定：

```c
motor_app_set_speed_test(50.0f, 50.0f);
```

落地循迹：

```c
motor_app_set_base_rpm(60.0f);
motor_app_set_line_follow_enabled(1u);
```

任何阶段停止：

```c
motor_app_stop();
```

这些入口后续应由比赛状态机调用，不应长期硬编码在 `main()` 中。

## 4. 灰度误差

通道 0 到 7 的默认权重为：

```text
-3500, -2500, -1500, -500, 500, 1500, 2500, 3500
```

有效探头集合为 $A$，位置误差为：

$$
e=\frac{\sum_{i\in A}w_i}{|A|}
$$

数字探头从一路切换到相邻一路时，原始误差会阶跃 1000。控制器先进行一阶低通：

$$
e_f[k]=e_f[k-1]+\alpha(e[k]-e_f[k-1])
$$

默认 `LINE_ERROR_FILTER_ALPHA=0.20`。减小该值会更平滑但增加转向延迟；增大则响应更快。

默认通道 7 方向为正。正误差经过循迹 PID 得到正差速量时，左轮加速、右轮减速。若实车转向相反，应整体反转权重顺序或交换差速符号，不要通过负 PID 增益修补。

当前安全策略：

- 无有效探头时，最多保持上一次误差 100 ms。
- 超过 100 ms 仍丢线，清空 PID 并停止电机。
- 灰度扫描序号超过 30 ms 不更新，按传感器故障停止。
- 同时触发不少于 6 路时置位 `marker_detected`，供后续 A 点横线状态机使用；当前不会自动停车。

## 5. 循迹外环

循迹控制使用滤波后的误差，输出左右轮转速差：

$$
\Delta n=K_pe+K_i\int e\,dt+K_d\frac{de}{dt}
$$

$$
n_L=n_b+\Delta n,\qquad n_R=n_b-\Delta n
$$

大偏差时基础速度从 `LINE_BASE_RPM_DEFAULT` 线性降到 `LINE_MIN_RPM_DEFAULT`。差速输出有限幅，左右轮目标还受 `LINE_TARGET_SLEW_RPM_PER_S` 限制；默认 300 RPM/s，即 10 ms 内最多改变 3 RPM。

## 6. 双轮速度环

每侧输出实现 `formula.md` 中的电机模型：

$$
u_m=k_S\operatorname{sgn}(n_r)+k_Vn_r+k_A\dot n_r
+K_p(n_r-n)+K_i\int(n_r-n)dt+K_d\frac{d(n_r-n)}{dt}
$$

电机标称最高转速为 **320 RPM**（`MOTOR_RATED_MAX_RPM`）。软件目标暂时限制为 250 RPM，供 $k_A$ 使用的目标加速度估计限制为 600 RPM/s，PWM 限制为 10000。

最终 PWM 还经过 `WHEEL_PWM_SLEW_DUTY_PER_S` 限制；默认 30000 duty/s，即 10 ms 内最多改变 300，防止新的灰度状态把阶跃电压直接施加到电机。安全停机不经过该限制。输出饱和且误差继续推动饱和时暂停积分。

## 7. 必做符号检查

修改 `control_config.h` 前先架空车轮：

1. 分别给左右轮正目标，确认两轮都向车辆前进方向转。
2. 正转时串口 `m=` 后对应实测 RPM 必须为正；否则修改 `WHEEL_LEFT_ENCODER_SIGN` 或 `WHEEL_RIGHT_ENCODER_SIGN`。
3. 将黑线依次移到通道 0 和通道 7，确认 `e=` 分别为负和正。
4. 在线位于车体右侧时，确认控制器使车辆向右修正。
5. 若黑线没有被判为有效，切换 `LINE_SENSOR_ACTIVE_LEVEL`，不要先调 PID。

## 8. 调参顺序

### 8.1 单轮开环辨识

暂时令轮速 PID 增益为零，逐级增加 PWM，记录每侧启动占空比和稳态 RPM：

- 启动占空比估计 $k_S$。
- 稳态 PWM-RPM 斜率估计 $k_V$。
- 左右轮分别辨识，不能直接共用参数。

### 8.2 架空轮速闭环

1. 先设 `kS/kV`，`Ki=Kd=0`，从小到大增加 `Kp`。
2. 能快速跟随且无持续振荡后，加入小 `Ki` 消除静差。
3. 一般不需要轮速 `Kd`；编码器 10 ms 计数分辨率有限，微分容易放大噪声。
4. 分别测试 30、60、100 RPM 和正反向阶跃。

### 8.3 落地直线

暂时令 `LINE_KP/KI/KD=0`，让两轮同速行驶。分别修正左右 `kV` 或速度环增益，保证直线不持续偏航。

### 8.4 循迹外环

1. 低速起步，只增加 `LINE_KP`，使车辆能回线但不过度摆动。
2. 加入少量 `LINE_KD` 抑制蛇形。数字探头切换会放大微分项，当前初值已从 0.0008 降至 0.00015。
3. 若单探头切换仍抖动，依次减小 `LINE_ERROR_FILTER_ALPHA`、降低 `LINE_TARGET_SLEW_RPM_PER_S`；若转弯明显迟钝则反向调整。
4. 最后才考虑很小的 `LINE_KI`，数字灰度循迹通常不需要较强积分。
5. 逐步提高基础 RPM，并重新调整弯道最低速度和差速限幅。

## 9. 串口遥测

活动模式下每 250 ms 输出：

```text
[ctl] mode,e=<误差>,n=<有效探头数>,t=<左右目标RPM>,m=<左右实测RPM>,u=<左右PWM>,s=<饱和标志>
```

调参时重点观察目标与实测方向是否一致、PWM 是否长期饱和、左右轮稳态误差是否不同。正式比赛前应降低或关闭文本遥测，改用定长二进制日志。

## 10. 后续工作

- 用实测数据填写左右轮 `kS/kV/kA` 和 PID 增益。
- 若后续需要更高车速，用加速度、加加速度受限的 S 曲线规划器替代当前一阶斜率限制。
- 将 `marker_detected` 接入 A 点检测和停车状态机。
- 将 IMU 航向角速度作为短时丢线预测的辅助量。
- 将车体规划加速度输出给滚球摆杆前馈。

# 两个开源车载平衡滚球项目控制律对比分析

> 分析日期：2026-08-04  
> 分析对象：`G431_26H-master` 与 `26电赛H题_车载平衡滚球运动控制系统`  
> 注：本文中的“控制率”统一按“控制律”理解。

## 1. 总体结论

两个项目采用的并不是同一种实现路线：

- `G431_26H-master` 是较规范的“观测器 + 位置/速度分层闭环 + 连续加速度前馈”。
- `26电赛H题_车载平衡滚球运动控制系统` 是“非线性增益调度 PID/PD + 赛道事件触发的固定角度前馈”。

前者的模型结构、时间处理、安全保护和工况泛化能力更好；后者针对固定比赛赛道和重复运动过程更直接，依靠大量实机经验参数获得较好的比赛效果。

对于当前 M0G3519 项目，更适合以第一个项目作为基础控制架构，选择性吸收第二个项目的接近目标增阻尼、任务状态机和已知事件前馈思想。

## 2. 项目一：G431_26H-master

### 2.1 实际启用的控制器

项目同时提供 PID 和 LADRC，但默认编译选项启用的是 PID：

```c
#define CONTROL_ALGORITHM_PID   0
#define CONTROL_ALGORITHM_LADRC 1
#define CONTROL_ALGORITHM CONTROL_ALGORITHM_PID
```

控制定时器周期为 10 ms，即 100 Hz。TIM6 在定时中断中调用 `control_beam()`，主循环负责 IMU、按键、任务状态机、电机通信和遥测。

主要源码：

- `A:/Downloads/G431_26H-master/CODE/pid.c`
- `A:/Downloads/G431_26H-master/CODE/pid.h`
- `A:/Downloads/G431_26H-master/CODE/camera_position.c`
- `A:/Downloads/G431_26H-master/CODE/ladrc.c`
- `A:/Downloads/G431_26H-master/Core/Src/main.c`

### 2.2 摄像头 Alpha-Beta 观测器

摄像头位置首先经过 Alpha-Beta 观测器：

```text
x_pred = x_hat + v_hat * dt
r      = x_camera - x_pred
x_hat  = x_pred + 0.85 * r
v_hat  = v_hat + 0.15 * r / dt
```

其中：

- `x_camera` 是摄像头测得的球位置偏差；
- `x_hat` 是估计位置；
- `v_hat` 是估计速度；
- `dt` 来自摄像头数据帧携带的真实时间戳，而不是假设固定帧率。

控制器取样时，还会用当前时间与最后观测时刻之间的差值继续外推位置：

```text
x_control = x_hat + v_hat * dt_extrapolation
```

这能减轻视觉帧率较低、帧间隔波动和通信延迟带来的相位滞后，是该项目稳定性较好的关键之一。

### 2.3 位置外环

位置误差定义为：

```text
e = x_hat - x_ref
```

控制器设置了位置修正迟滞：

```text
|e| >= 0.2：开始修正
|e| <= 0.1：停止修正
```

这样可以避免误差在边界附近反复触发控制。

位置外环不是直接输出摆杆角度，而是生成目标钢球速度：

```text
v_limit = min(v_max, sqrt(2 * Kbrake * |e|))

v_ref = -sat(Kp * e + Ki * integral(e), +/-v_limit)
```

默认参数为：

```text
Kp       = 1.51
Ki       = 0.10
v_max    = 20.0
Kbrake   = 5.0
```

`sqrt(2*a*s)` 来源于匀减速运动关系。球离目标越近，允许的目标速度越低，因而形成一个具有物理意义的制动速度包络。这比单纯依赖增大 D 参数抑制过冲更容易解释和整定。

积分项带有限幅和条件积分。输出已饱和且误差仍推动饱和加深时，不继续累计积分；当误差方向有助于退出饱和时，允许积分更新。

### 2.4 速度内环与加速度阻尼

项目利用观测器得到球速度，并对速度差分得到的球加速度进行一阶低通：

```text
a_ball = (v_hat[k] - v_hat[k-1]) / dt
a_ball_f = a_ball_f + 0.2 * (a_ball - a_ball_f)
```

最终摆杆角速度控制律为：

```text
omega_beam = Kv * (v_hat - v_ref)
           + Ka * a_ball_f
           + omega_ff
```

默认参数为：

```text
Kv = 0.40
Ka = 0.25
```

其中 `Kv` 提供球速度反馈，`Ka` 相当于额外的加速度阻尼。控制输出限幅到 `+/-35 deg/s`，然后根据机械正、负方向不同的传动比换算成电机 RPM：

```text
motor_rpm = omega_beam * transmission_ratio / 6
```

项目使用速度型摆杆控制，而不是每周期直接跳变到一个目标角度，因此执行机构动作更连续。

### 2.5 车辆加速度前馈

任务 3 使用 IMU Z 轴加速度。实际代码中的前馈链为：

```text
a_corrected = IMU_Z - acceleration_bias
a_f = a_f + alpha * (a_corrected - a_f)

theta_ff = theta_baseline
         + sat(-Kff * a_f, +/-3 deg)

omega_ff = sat(Kangle * (theta_ff - theta_beam), +/-10 deg/s)
```

默认参数为：

```text
Kff    = -2.0 deg/(m/s^2)
Kangle = 5.0 1/s
alpha  = 0.15
bias   = 0.565 m/s^2
```

前馈使用三态状态机：

```text
IDLE -> ACTIVE -> RETURNING -> IDLE
```

实际代码的触发条件为：

```text
进入：|a_f| > 0.08 m/s^2，持续 30 ms
退出：|a_f| < 0.05 m/s^2，持续 150 ms
回位：摆杆回到基准角度误差 0.1 deg 内
```

前馈还有位置相关权重：

```text
scale = sat(1 - |x - x_ref| / 1.0, 0, 1)
omega_ff = omega_ff * scale
```

球靠近目标时，车辆前馈充分工作；球已经明显偏离目标时，前馈逐渐退出，让位置反馈优先救球。这种控制权分配能减少前馈和反馈互相冲突。

从简化动力学看，更具有物理意义的车辆加速度前馈是：

```text
theta_ff = atan(-a_vehicle / g)
```

小角度下可近似为 `theta_ff ~= -a_vehicle/g`。项目中的 `Kff` 本质上是把该物理关系、IMU 安装方向、机械传动误差和实机保守系数合并成一个可调增益。

### 2.6 静态锁定与保护

当球满足以下条件 500 ms：

```text
|x - x_ref| <= 0.1
|v_hat| <= 0.1
```

项目进入静态锁定，将输出置零；球移动超过 0.2 后恢复控制。这样可以利用静摩擦减少电机抖动，但它并不是真正持续保持的闭环，小扰动可能不会立即被修正。

其他保护包括：

- 丢球后进入安全状态；
- 摄像头通信和时间戳超时检测；
- 电机位置反馈新鲜度检测；
- 电机机械软限位和硬边界；
- 输出有限值检查；
- 积分限幅与抗饱和；
- 前馈进入/退出滞回；
- 可选的机械卡滞点补偿。

### 2.7 LADRC 备选控制器

LADRC 实现包含二阶跟踪微分器、三阶线性扩张状态观测器和总扰动补偿。

其控制律可概括为：

```text
feedback = wc^2 * (x1 - z1) + 2*wc * (x2 - z2)
u = (feedback - z3) / b0
```

默认参数：

```text
wc = 25 rad/s
b0 = 10.5
Ts = 0.010 s
u  in [-35 deg, +35 deg]
```

其中 `z3` 估计模型误差和外界扰动，`-z3/b0` 是扰动补偿量。

需要注意，LADRC 版本直接输出目标摆杆角度并采用电机位置模式，而 PID 版本输出摆杆角速度并采用电机速度模式。两种执行接口不同，不能只替换控制器公式而沿用相同参数。当前默认成功方案仍然是 PID 分层控制。

### 2.8 文档与代码不一致之处

实机调参应以代码为准，当前发现的主要差异如下：

| 项目 | 调参文档 | 实际代码 |
|---|---:|---:|
| IMU 轴 | 文档部分位置称 AccY | 使用 Z 轴 `acceleration_mps2[2]` |
| 前馈角度限幅 | `+/-7 deg` | `+/-3 deg` |
| 前馈进入阈值 | `0.15 m/s^2` | `0.08 m/s^2` |
| 前馈进入时间 | `50 ms` | `30 ms` |
| 前馈退出时间 | `200 ms` | `150 ms` |

## 3. 项目二：26电赛H题_车载平衡滚球运动控制系统

### 3.1 总体结构

该项目基于 10 ms 定时中断运行控制任务，即控制频率为 100 Hz。5 ms 定时器独立采集左右轮编码器速度并累计里程。

系统包含两部分：

1. K230 摄像头位置到云台舵机角度的滚球控制；
2. 灰度循迹外环和左右轮速度 PI 内环组成的小车运动控制。

主要源码：

- `A:/Downloads/26电赛H题_车载平衡滚球运动控制系统/keil/empty.c`
- `A:/Downloads/26电赛H题_车载平衡滚球运动控制系统/keil/hardware/pid.c`
- `A:/Downloads/26电赛H题_车载平衡滚球运动控制系统/keil/hardware/pid.h`
- `A:/Downloads/26电赛H题_车载平衡滚球运动控制系统/keil/hardware/uart.c`

### 3.2 球位置和速度

K230 通过串口发送球坐标，控制器直接使用 `x_site`。代码没有携带或使用摄像头时间戳，也没有对坐标新鲜度进行超时判断。

球速度估计为：

```text
v[k] = 0.6 * v[k-1] + 0.4 * (x[k] - x[k-1])
```

这个速度的单位是“像素/控制周期”，不是“像素/秒”。只要控制周期稳定在 10 ms，参数可以通过经验调通；如果控制周期变化或摄像头帧率变化，速度尺度和 D 项强度也会变化。

### 3.3 非线性增益调度 PID/PD

位置误差定义为：

```text
e = x - x_ref
```

默认参数约为：

```text
Kp = 0.12
Ki = 0.002
Kd = 0.36~0.40
```

比例项为：

```text
P = Kp * e
```

积分项在接近目标时降低累计速度：

```text
if |e| < 30:
    integral += 0.3 * e
else:
    integral += e

integral = sat(integral, +/-200)
I = Ki * integral
```

微分项不是线性 `Kd*v`，而是根据球速、剩余距离和运动方向动态增强：

```text
speed_gain = 1 + 0.8 * |v|

if |e| < 100:
    distance_gain = 1 + (100 - |e|) / 25
else:
    distance_gain = 1

approaching = 球正在朝目标运动
approach_gain = 1.8 if approaching else 1

D = Kd * v * speed_gain * distance_gain * approach_gain
```

最终输出为：

```text
correction = sat(P + I + D, +/-dynamic_limit)
servo_angle = sat(31.2 deg - correction, 3 deg, 45 deg)
```

动态输出限幅为：

```text
|e| <= 100：20 deg
|e| > 100 ：25 deg
|e| > 150 ：30 deg
```

因此，这个控制器本质上是“位置 PID + 随状态变化的非线性 D 阻尼”。球越快、离目标越近、并且正在接近目标时，阻尼越强。

### 3.4 强制制动与死区

当球接近目标但速度仍较大时：

```text
|e| < 15
|v| > 0.5
球正在朝目标运动
```

控制器直接将舵机置于机械中位 `31.2 deg`。这相当于跳过普通 PID 输出，使用经验规则进行强制刹车。

当满足：

```text
|e| <= 5
|v| < 1
```

控制器保持当前舵机角度，不再更新。这可以减少舵机来回抖动，但保留的角度不一定恰好是水平角，如果积分或上一次控制输出存在偏置，仍可能导致球缓慢漂移。

### 3.5 小车循迹和轮速控制

小车使用典型的串级控制：

```text
灰度位置偏差 PID
        |
        v
左右轮目标速度差
        |
        v
左右轮速度 PI
        |
        v
左右电机 PWM
```

灰度循迹外环默认参数为：

```text
Kp = 0.95
Ki = 0
Kd = -0.35
```

外环输出用于差速：

```text
v_left_ref  = v_car - steer_output
v_right_ref = v_car + steer_output
```

左右轮速度 PI 默认参数为：

```text
Kp = 33
Ki = 1.2
Kd = 0
```

轮速控制器直接输出电机 PWM。和滚球控制一样，通用 PID 函数的积分与微分都没有显式乘除 `dt`，因此所有参数均隐含依赖 10 ms 调用周期。

### 3.6 起步和停车前馈

该项目的车辆前馈不是根据 IMU 加速度连续计算，而是基于任务事件执行固定动作。

典型起步前馈：

```text
检测 Grey_Speed 从 0 变为正值
-> Q3_Feedforward_Cnt = 25
-> 舵机设置为 31.2 + 30 = 61.2 deg
-> 持续约 25 * 10 ms = 250 ms
```

典型停车前馈：

```text
车辆里程超过预设制动触发距离
-> 舵机提前后仰到约 7~10 deg
-> 持续若干控制周期
-> 同时将轮速目标设置为 0，进行主动制动
```

部分任务根据目标球位置的绝对值调整停车补偿：

```text
brake_distance = 550 - 0.04 * |target|
brake_ticks    = 12 + 0.052 * |target|
brake_angle    = 6 + 0.032 * |target|
```

这属于根据赛道和任务目标拟合出的经验调度表。它可以在固定车速、固定路面和固定机械结构下取得很好的效果，但一旦车辆质量、电池电压、加速度、路面摩擦或控制周期改变，就需要重新标定。

### 3.7 工程风险

该项目虽然实用，但存在以下风险：

- 摄像头数据没有时间戳和超时保护，旧坐标可能持续参与控制；
- 球速度没有除以真实 `dt`，参数依赖固定周期和摄像头帧率；
- 舵机输出饱和时积分仍可能继续累计；
- 固定角度前馈切换较硬，可能造成执行器冲击；
- 死区内保持旧舵机角度，可能保留不必要的倾角；
- 在 10 ms 定时中断内执行 `sprintf` 和串口发送，可能引入控制周期抖动；
- IMU 虽然存在，但没有用于滚球闭环的连续车辆加速度补偿；
- 大量任务参数直接写在状态机分支中，可移植性和可维护性较弱。

## 4. 两个项目的控制律对比

| 对比项 | G431_26H-master | 车载平衡滚球项目 |
|---|---|---|
| 控制周期 | 10 ms / 100 Hz | 10 ms / 100 Hz |
| 滚球结构 | 位置 PI + 球速度/加速度反馈 | 非线性增益调度 PID/PD |
| 位置处理 | Alpha-Beta 观测器 | 直接使用摄像头像素 |
| 速度估计 | 使用真实时间戳 | 相邻位置差分低通 |
| 外环输出 | 目标球速度 | 舵机角度修正量 |
| 执行量 | 摆杆角速度 | 舵机绝对角度 |
| 抗过冲 | 物理制动速度包络 | 动态 D 增益 + 强制回中 |
| 车辆补偿 | IMU 连续加速度前馈 | 起步/停车固定角度动作 |
| 前馈与反馈协调 | 按球位置误差连续衰减 | 状态机直接切换 |
| 积分抗饱和 | 条件积分 + 限幅 | 仅积分限幅 |
| 数据超时保护 | 摄像头和电机反馈均检查 | 摄像头无新鲜度检查 |
| 机械保护 | 软限位、边界、反馈年龄检查 | 舵机角度限幅 |
| 工况泛化能力 | 较强 | 依赖固定赛道和实机标定 |

## 5. 为什么两个项目都能取得较好效果

### 5.1 第一个项目成功的原因

1. 视觉数据的时间尺度处理正确，速度估计较可信。
2. 外环决定球应当怎样移动，内环负责产生摆杆动作，职责清楚。
3. 使用制动速度包络主动限制接近目标时的速度。
4. IMU 前馈在车辆扰动影响到球位置之前就开始补偿。
5. 通过滞回、限幅、超时和安全状态减少异常工况导致的失控。

### 5.2 第二个项目成功的原因

1. 比赛工况重复，允许通过实机试验获得高度针对性的参数。
2. 动态放大 D 项对接近目标时的过冲有直接抑制作用。
3. 起步和停车是最主要的车辆扰动，固定动作前馈正好覆盖这些事件。
4. 控制结构简单、执行路径短，舵机响应直观。
5. 任务状态机把不同赛题分别调参，不追求一套控制律覆盖所有工况。

第二个项目的成功不代表其固定前馈角度可以直接移植。它更接近“针对已知赛道的系统级标定”，而不是与机械结构无关的通用控制器。

## 6. 对当前 M0G3519 项目的建议

### 6.1 推荐总体结构

```text
摄像头位置与时间戳
        |
        v
Alpha-Beta 或等价状态观测器
        |
        +--> 估计位置
        +--> 估计速度
        |
        v
位置 PI + 制动速度包络
        |
        v
目标球速度
        |
        v
球速度反馈 + 适量加速度阻尼
        |
        +<-- IMU 车辆加速度前馈
        |
        v
摆杆目标角速度/角度
        |
        v
执行机构闭环与机械限位
```

### 6.2 建议保留的项目一设计

- 摄像头真实时间戳；
- Alpha-Beta 位置/速度观测；
- 位置外环生成目标球速度；
- `sqrt(2*a*s)` 制动速度包络；
- 条件积分抗饱和；
- IMU 连续加速度前馈；
- 前馈进入/退出滞回；
- 前馈按球位置误差衰减；
- 摄像头、电机反馈超时保护；
- 摆杆机械软限位。

### 6.3 可吸收的项目二设计

- 接近目标时逐渐增强速度阻尼；
- 到位判定同时检查位置误差和球速度；
- 任务目标使用斜坡或轨迹发生器渐变，避免目标阶跃；
- 已知起步、停车事件可用于提前激活前馈状态机；
- 不同任务可以使用不同目标轨迹，但不建议复制固定舵机大角度。

### 6.4 不建议直接移植的内容

- 固定 `61.2 deg`、持续 `250 ms` 的起步动作；
- 根据固定里程写死的停车舵机角度；
- 未除以 `dt` 的速度估计；
- 在控制中断内执行格式化和阻塞串口发送；
- 死区内永久保持上一次非水平舵机角度；
- 控制输出饱和后仍无条件累计积分。

## 7. 推荐调参顺序

```text
1. 标定摄像头位置方向、比例和时间戳
2. 标定摆杆零位、方向、传动比和机械限位
3. 关闭积分、加速度阻尼和车辆前馈
4. 调整 Alpha-Beta 观测器，使速度平滑且延迟可接受
5. 只调球速度反馈内环，确认倾斜方向和阻尼方向
6. 调位置比例 Kp 和最大目标球速度
7. 调制动参数 Kbrake，重点观察接近目标时的过冲
8. 加入少量 Ki 消除静态偏差，并检查抗饱和
9. 加入适量球加速度阻尼 Ka
10. 标定 IMU 零偏、安装轴向和低通参数
11. 从很小的车辆加速度前馈增益开始调节
12. 最后增加起步/停车事件的提前触发，不直接切固定大角度
```

最终判据不应只看球是否偶尔停在目标点，还应同时检查：

- 多次重复启动和停车时的最大偏移；
- 不同电池电压和车辆载荷下的表现；
- 摄像头丢帧或延迟时是否进入安全状态；
- 输出是否频繁达到机械限位；
- 积分是否长期饱和；
- 前馈退出后摆杆能否平滑回到正常平衡状态。
